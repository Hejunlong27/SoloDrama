# 项目预算管理

在“设置 → 插件管理 → 项目预算管理”中配置默认币种和预警阈值。预算数据保存在当前项目的 `.solodrama/budget.json`，不同项目互不影响。

Agent 可使用：

- `summary`：读取预算、已记录成本、剩余额度、消耗比例和未知成本数量。
- `setBudget`：设置项目总预算。
- `record`：记录真实成本，可附类别、供应商、模型、任务 ID 和备注。
- `removeEntry`：删除用户明确要求撤销的一笔成本记录。

没有供应商返回金额时使用 `recordUnknown`，不会把未知费用当作 0。付费生成前应先检查预算和报价。
