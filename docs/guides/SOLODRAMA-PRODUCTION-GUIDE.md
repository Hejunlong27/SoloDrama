# SoloDrama 3.0 短剧制作指南

本指南描述如何从故事创意走到可播放成片。

## 1. 打开统一工作台

1. 打开一个 SoloDrama 项目。
2. 在底部面板切换器选择“工作台”。
3. “制作”已并入工作台，不再作为独立入口。
4. 首次打开时自动创建 `.solodrama/production.json`，不会修改旧画布。

## 2. 配置模型

制作引擎复用现有设置：

- 语言模型：设置 → 语言模型，用于剧本理解。
- 图片模型：设置 → 媒体模型，用于角色、场景、道具和分镜图。
- 视频模型：设置 → 媒体模型，用于镜头 Take。
- 音频模型：设置 → 媒体模型，用于配音、音乐和音效。
- ComfyUI / RunningHub / Cloud Hub：沿用现有 Provider 与 Workflow 配置。

不同 Workflow 支持参数不同。页面会把可用参考图放进统一请求，最终能力由 Provider 适配器判断。

## 3. 画布来源

“画布来源”页签会扫描当前项目的旧画布节点：

- 文本节点可导入为分集剧本。
- 图片节点可导入为角色、场景、道具或普通素材。
- 视频节点可导入为未归档镜头和 Take。
- 音频节点可导入为 Production 音频素材。

导入只创建 Production 实体并保存 `canvasBindings` 映射，不修改原画布。同一来源不能重复导入；需要修改正式内容时，应回到对应制作阶段编辑。

## 3. 剧本理解

1. 进入“剧本理解”页签。
2. 选择输入类型：故事创意、故事大纲、小说、剧本或分集剧本。
3. 选择语言模型。
4. 粘贴文本。
5. 选择要生成的部分。
6. 点击“开始理解”。
7. 检查人物、场景、道具、分集和连续性提示。
8. 点击“应用到未确认部分”。

说明：

- 长文本会自动分段。
- 应用时按名称复用已有角色、场景和道具。
- AI 不会覆盖已确认内容。
- 可在“故事与剧本”区域确认简介、世界观和时间线。
- 角色、场景、道具和镜头可在各自页面中确认。

## 4. 角色与场景

进入“角色与场景”页签：

1. 选择角色、场景或道具。
2. 编辑档案和视觉设定。
3. 点击“生成角色/场景/道具参考图”。
4. 任务完成后，在“选择已生成图片”中选择结果。
5. 点击“设为参考图”。
6. 点击“查询受影响镜头”查看该设定关联的 Shot。

角色：

- Visual Profile 包含面部、发型、身材、风格。
- 可新增多个服装版本。
- 可设置配音 Provider、Voice ID、语速和语言。

确认后，AI 重生成默认跳过该实体。取消确认后可继续编辑和重新生成。

## 5. 分镜与镜头

进入“分镜与 Take”页签：

- 左侧显示“集 → 场 → 镜头”。
- 选择镜头后可编辑：
  - 标题、时长、景别、角度、运镜。
  - 画面、动作、人物位置与表情。
  - 对白、环境音。
  - 首帧、尾帧、视频提示词。
- “拆分”会在当前镜头后创建稳定 ID 的新镜头。
- “合并下一镜”会保留并重新归属 Take。
- “上移/下移”调整镜头顺序并重排镜号。
- “批量分镜图”为当前未确认且没有分镜图的镜头提交图片任务。
- “批量镜头”为当前分集没有正式 Take 的镜头提交视频任务。

## 6. 生成 Take

1. 选择图片或视频模型。
2. 可填写 Workflow ID 和实例 ID。
3. 提示词留空时，从镜头结构化字段自动组装。
4. 点击“生成 Take”。

每次生成只新增 Take，不覆盖旧 Take。

任务状态：

- 页面每 5 秒同步一次。
- 断线或重启后，任务会按已有 taskId 恢复或标记为失败。
- “取消”只取消对应 taskId。
- 生成成功的 Take 仍处于未正式状态。

选择正式版本：

1. 在 Take 列表检查 Provider、Model、耗时和输出。
2. 点击“设为正式”。
3. 该 Take 写入视频时间轴；同镜头旧正式 Take 不会删除，仍保留在历史中。

## 7. 配音、音乐和音效

- “生成配音”使用镜头对白和角色音色配置。
- 配音成功后自动新增对白音频轨和字幕轨。
- “音乐与音效”可生成背景音乐或音效。
- 可在时间轴中修改开始时间、持续时长、轨道、音量和字幕文字。

## 8. 时间轴与导出

进入“声音与成片”页签：

1. 检查视频、对白、字幕、音乐和音效轨。
2. 选择画幅：9:16、16:9、1:1。
3. 设置分辨率、帧率和格式。
4. 设置输出文件名，例如 `outputs/episode-01.mp4`。
5. 点击“导出成片”。

导出规则：

- 只使用已选择的正式 Take。
- 已有文件不会被覆盖。
- 视频按镜头顺序拼接，短素材会补齐到镜头时长。
- 音频与视频混合。
- 输出后自动记录新的视频 Asset 和全部来源 ID。

## 9. 数据与恢复

- 领域数据：`.solodrama/production.json`
- 媒体任务：SoloDrama 数据目录中的 `mediaTasks`
- 生成素材：默认 `assets/production/*`
- 成片：由用户填写的工作区相对路径决定

不要在升级、修复或重启时删除用户项目目录。程序文件、用户配置、项目数据和日志应由桌面发行版分别管理。

## 10. 常见问题

### 页面没有模型

先到设置配置对应模型。没有配置 Provider 时，任务会失败且不会产生可用 Take。

### 任务中断

点击“同步任务”。能恢复的任务会继续；缺少供应商凭据或任务记录时会明确失败，不会自动重复扣费。

### 导出找不到 FFmpeg

按 FFmpeg 设置安装或指定可用版本。

### 导出失败但视频片段存在

先检查每个 Shot 是否已选择正式 Take，再检查 Take 输出 Asset 和工作区路径。
