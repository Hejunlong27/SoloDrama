# SoloDrama Launcher 用户指南

## 启动

安装完成后，双击桌面上的 SoloDrama 图标。

- 正常启动会显示短暂品牌启动画面。
- 完成后自动进入 SoloDrama。
- 首次启动会先显示启动控制中心，确认运行环境和数据位置后进入软件。
- 启动失败会显示错误和日志路径。

不需要打开终端，也不需要在首次启动时配置 ComfyUI。

## 打开启动控制中心

进入工作台后，点击顶部菜单中的火箭图标，可以打开启动控制中心。

控制中心可以查看：

- 本地后端是否正常。
- 项目数据目录是否可访问。
- 云端 ComfyUI 实例数量。
- 当前任务概况。
- 日志和诊断信息。
- 应用版本与运行平台。

## 运行日志

打开“运行日志”：

- 可按 INFO、WARN、ERROR 过滤。
- 可搜索关键字。
- 可复制当前筛选结果。
- 可打开日志目录。
- 可导出诊断 JSON。

日志中的 Token、密码、Authorization、Cookie 和常见密钥字段会脱敏。

## 启动设置

### 启动后自动进入工作台

开启时，后续启动健康检查完成后自动进入工作台。关闭后每次启动停留在控制中心。

### 启动时检查更新

关闭后只停止后台自动检查，仍可在“关于”页手动检查更新。

### 开机自启动

Windows 正式安装版可为当前用户注册开机启动项。开发模式不允许注册。

## 数据和日志位置

新安装默认使用系统应用数据目录：

- Windows：`%APPDATA%\SoloDrama\data`
- macOS：`~/Library/Application Support/SoloDrama/data`
- Linux：`~/.local/share/solodrama/data` 或 XDG 数据目录

日志单独保存：

- Windows：`%APPDATA%\SoloDrama\logs`
- macOS：`~/Library/Logs/SoloDrama`
- Linux：`~/.local/state/solodrama/logs`

如果旧版本已经在安装目录 `data/` 中保存项目，启动器会优先继续使用旧目录，避免升级后找不到项目。

## 升级

升级只替换程序文件。

不会删除：

- 项目。
- 工作流。
- Provider 配置。
- API Token。
- 用户素材。
- 日志。

卸载程序只有在用户明确勾选“同时删除用户数据”时才删除数据。

## 云端任务与退出

Launcher 不管理云端任务，也不会因为关闭窗口而向云端发送取消。

已经提交的任务由 SoloDrama Task Runtime 保存任务 ID、ProviderTaskData 和状态。下次启动后可继续核实和恢复。

## 常见问题

### 启动失败

查看错误弹窗中的日志路径，从控制中心“运行日志”或日志目录查看详细错误。

### 数据目录不可访问

确认目录权限和磁盘空间。不要手动删除整个数据目录。

### 云端实例离线

云端离线不会阻止进入工作台。可在“云端算力中心”重新检测，已提交任务仍由 Task Runtime 持久保存。

### 打开日志目录没有反应

确认当前为桌面客户端；浏览器模式和移动端没有本机目录权限。

## 当前限制

- 当前构建环境未能生成 Electrobun SDK 和桌面安装包。
- 系统托盘和托盘菜单尚未实现，不能用假入口代替。
- 首次向导暂不提供在应用内切换数据目录，可使用 `SOLODRAMA_DATA_DIR` 或后续安装向导能力。
