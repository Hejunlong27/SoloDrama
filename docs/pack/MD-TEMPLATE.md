# 制作包 Markdown 模板（通道 B）

> 给「习惯产出 Markdown、但不想手写 JSON」的创作 Skill 用。
> 按本模板产出的单个 Markdown，引擎可用规则解析（零 LLM、零成本、可复现）。
> 若 Skill 的输出格式与本模板不同，走通道 C：`IMPORT-PROMPT.md`。

## 一、单文件形态

一个 Markdown 装完整季：

```
<!-- pack
title: 亿万丈夫的三个月合约
slug: billionaire-contract
episode_count: 30
target_duration: 240
style_lock: 美式复古影视风格，胶片颗粒，年代色偏，自然窗光与钨丝灯，轻微褪色
negative: 多余手指，五官扭曲，比例失调，Q版，卡通，真人实拍，文字，水印
-->
```

- 文件头用 HTML 注释包住 `pack` 元信息，渲染时不可见。
- 字段同 `PACK-SPEC.md` §3；`episode_count` 必填。
- 注释块必须出现在文件最前 20 行内。

## 二、资产段

```markdown
## 资产

### P01 何暖
- role: 女主，28 岁，建筑设计师
- anchors: 左眉尾有一颗小痣；常戴细银链

#### LOOK-A 职场装
- aspect: 9:16   # 与出片画幅一致，横图当参考会被拉伸
- episodes: ep01,ep02,ep03
```text
美式复古影视风格角色设定图，胶片颗粒质感……（完整提示词，逐字使用）
```

#### LOOK-B 居家装
- episodes: ep04
```text
（完整提示词）
```

### S01 客厅
- role: 老式公寓客厅，60 平米

#### 空景
- episodes: ep01,ep03
```text

```
```

解析规则（严格）：

| 层级 | 语法 | 含义 |
|---|---|---|
| 一级 | `## 资产` | 资产段开始；到下一个 `## 第NN集` 为止 |
| 二级 | `### <ID> <名字>` | 一个资产；ID 必须符合 `P/S/D/FX` + 数字 |
| 三级 | `#### <code> <标签>` | 一个变体；code 为 `LOOK-A` / `空景` / `状态1` 等 |
| 元信息 | `- key: value` | 紧随 `###` 或 `####` 之后的行 |
| 提示词 | ` ```text ` 围栏 | 该变体的提示词；一个变体一个围栏 |

- `aspect` 缺省取 `pack.aspect`；`episodes` 缺省为空（表示全季可用）。
- 一个资产下没有 `####` 时，把 `###` 后第一个围栏当作唯一变体，code 记为 `base`。
- 围栏语言标记写 `text` 或留空都可以；写 `board` / `video` 的会被识别为镜头块，不在此处解析。

解析规则：

| 元素 | 语法 | 说明 |
|---|---|---|
| 集头 | `## 第NN集 <集名>` | NN 为 1–3 位数字；与文件内顺序无关 |
| 集元信息 | `- duration_total: 63` | 可选 |
| 镜头 | `### shot_NNN` | NNN 三位起，集内连续 |
| 镜头元信息 | `- key: value` | `duration` / `ratio` / `cast` / `dialogue` |
| `cast` | 逗号分隔，`P01 LOOK-A` 或 `P01` | 顺序即参考槽顺序 |
| `board` 块 | ` ```board ` | 必需；缺失则告警 |
| `video` 块 | ` ```video ` | 必需；缺失则导入失败 |
| `dialogue` | `资产ID|起|止|文本` | 可多行；起止单位秒 |

- `cast` 里资产的 `variant` 必须在资产段里存在，否则导入失败。
- 一个文件可以只写一集（多文件时按 `## 第NN集` 合并）。

## 五、与「总裁甜宠」类 Skill 的差异

现有创作 Skill（如 `tianchong-manju`）产出的是**人读版**手册：
时间轴总表 + 每镜 A/B 两段 + 制作信息 + 连续性检查。

这类输出**不满足**本模板的严格层级（资产是表格与行内提示词，镜头没有 `### shot_NNN` 标记），
所以：

- **不要**试图让规则解析器兼容它——兼容一套自由格式，等于写一个 Markdown 解释器。
- 走通道 C：用 `IMPORT-PROMPT.md` 让 LLM 做一次转换，产出本模板或原生 JSON。
- 转换结果落 `pack/` 目录后，后续所有环节与通道 A/B 完全一致。
