# H3 多参（Ref2VA）视频提示词 · 锁定契约

> 生效：2026-11-06（V0.7.72）｜判据真源：`stages/import/h3_prompt.py`
> 结构口径来自官方 `h3-prompt-writing/references/ref-en.txt`；本文件是它在**本管线**里的落地约定。

## 0. 一句话

进入视频生成环节的 `video_prompt` **必须是 H3 多参（Ref2VA）六段式**。
不是六段，导入直接阻断（`SHOT019` / `SHOT020`）——因为它不是「格式偏好」，是**参考图到底指谁**的唯一说明。

## 1. 为什么锁死，而不是「建议这样写」

2026-11-06 之前的写法长这样（真实项目原文）：

```
上传顺序：Mixed 1＝shot_001 分镜图｜Mixed 2＝P01 时小满 主卡｜…
资产图锚定：
角色 时小满 的参考图是 {{Mixed 2}}
0-4秒：
画面：中景。时小满蹲在纸箱前……
```

三个问题叠在一起：

| 问题 | 后果 |
|---|---|
| `{{Mixed 2}}` 是本仓库的占位符，**H3 不认识** | 它被当正文读进去；参考图上传了，但没被点名 —— 模型只能靠猜 |
| 没有 `subject_definitions` | 「第 2 张图是谁、要保留什么」全靠模型从图里自己归纳，一集一个样 |
| 「上传顺序：Mixed 1＝…」整行是中文+符号 | 会被当成「画面中应出现的文字」，有概率烧进画面（和 `<d>` 那条同源） |

**六段式的价值就在第二条**：它把「这张图是谁、保留到什么程度、第几秒出现」写成模型能读的声明。
所以这条不能只写在文档里靠自觉 —— 写成可执行判据，转换时归一、导入时阻断。

## 2. 六段结构（顺序不可改）

段名恒为英文小写 + 半角/全角冒号，独占行首（允许行内接正文）。

| # | 段 | 写什么 | 判据 |
|---|---|---|---|
| 1 | `subject_definitions` | 每张参考图是什么；每个 `<Subject n>` 来自哪张图 | 必须有 ≥1 个 `<Subject n>`，编号 1..N 连续，每个都引用 `<Picture k>` |
| 2 | `summary` | `[任务类型]` + 一段话：目标视频 + 参考关系 | 必须以 `[` 开头，类型取自固定枚举 |
| 3 | `retention_analysis` | 每个已定义标签一行 + 关系标记词 | 每个 Subject（及独立定义的 Picture）都要有一行，标记词只能取枚举值 |
| 4 | `detailed_description` | 正文：先立画风，再按 `[Shot n]` / `At MM:SS.mmm` 写动作、运镜、台词 | 要有 `[Shot 1]`；第 2 镜起必须有时间戳；时间戳不得早于/等于本镜时长 |
| 5 | `overall_soundscape` | 环境音、物理动作音、非语言人声 | 台词不写在这里 |
| 6 | `non_diegetic_music` | 只有观众听得见的配乐 | 没有就写 `N/A`，不要留空 |

### 2.1 标签

| 标签 | 用在哪 | 本管线的约定 |
|---|---|---|
| `<Picture n>` | 参考图 | **编号 = 上传顺序**：`1` 是分镜图（若本镜有），`2` 起按 `cast` 顺序逐个排 |
| `<Subject n>` | 可复用的可见内容（人 / 景 / 道具 / 特效） | 一条一个主体，定义里必须写「是 `<Picture k>` 中的…」 |
| `<Audio n>` | 音色 / 配乐参考 | 本管线暂不上传音频参考；用了就是悬空标签，判据会拦 |
| `<Video n>` | 视频参考 | **禁止**：本管线没有视频参考槽，写了无法绑定 |

`<Picture n>` 与 `<Subject n>` 是两套独立编号。前者说「图从哪来」，后者说「这是谁」——
一句话里出现 `<Subject 2>（S1）` 的意思是：**第 2 号主体的第 1 个说话人**。

### 2.2 时间轴

- `[Shot 1]` 不带时间戳（它就是 0 秒）。
- 第 2 镜起：`[Shot 2] At 00:04.000，……`（毫秒三位，中文逗号或英文逗号都认）。
- 时间戳是本镜内的相对时间，**必须早于本镜时长**；超出的部分会被模型截掉。
- 一镜（一个 pack shot）内部可以切 1–4 个 `[Shot n]` —— 这是 H3 的段内切镜，不增加计费段数。

### 2.3 说话人

- 按**发声顺序**编号 `(S1)` / `(S2)`，中文正文里写成 `（S1）` 或 `(S1)` 都认。
- 同一个人跨镜复用同一个编号；`<Subject n>（S1）` = 这个主体在说话。
- 有 `<d>` 台词却全文没有 `(Sx)` → 告警 `H3-W05`（多人对话会分不清谁在说）。
- 不开口的角色写「闭口」，不要给他加 `<d>`；画外音只写在 `overall_soundscape`。

## 3. 完整样例（本管线口径）

```
subject_definitions:
<Picture 1> 是本镜分镜图（首帧构图锚点）：中景，何暖居左、靳衍居右，合约在桌面中央。
<Subject 1> 是 <Picture 2> 中的何暖：二十七八岁，黑色低马尾，炭灰西装外套，白衬衫。
<Subject 2> 是 <Picture 3> 中的靳衍：三十岁上下，深灰三件套，袖口露出银色腕表。
<Subject 3> 是 <Picture 4> 中的会议室：玻璃幕墙、深色长桌、冷白顶灯。

summary:
[reference generation] 目标视频呈现 <Subject 1> 把合约推到 <Subject 2> 面前的一拍，参考图提供两人形象与 <Subject 3> 的空间结构。

retention_analysis:
<Subject 1>（出现于 [Shot 1]）：fully_preserved - 保留低马尾、炭灰西装与面部。
<Subject 2>（出现于 [Shot 1]）：fully_preserved - 保留深灰三件套与银色腕表。
<Subject 3>（出现于 [Shot 1]）：fully_preserved - 保留幕墙、长桌与顶灯。
<Picture 1>（[Shot 1] 首帧）：partially_preserved - 保留机位与左右站位。

detailed_description:
目标视频为冷调写实的现代职场质感：玻璃幕墙把窗外天光折成条状高光，冷白顶灯压住整体色温，画面低饱和偏灰蓝，暗部保留细节。
[Shot 1] 中景，平视机位，<Subject 1> 坐在长桌左侧，右手把合约沿桌面推向对面，指尖在纸角停住；<Subject 2> 坐在右侧，身体略前倾，垂眼看向封面。镜头固定，带极轻微的手持呼吸感。
<Subject 1>（S1）说：<d>[Chinese] 一年，互不干涉。</d>
[Shot 2] At 00:05.000，镜头沿桌面缓推到两人之间，景别收到近景，<Subject 2> 抬眼看向她，右手食指在桌面轻敲两下。

overall_soundscape:
空调低鸣，纸张在桌面摩擦的沙沙声，椅脚轻响。

non_diegetic_music:
N/A
```

对应关系（本镜 `cast` = `P01@LOOK-A, P02@LOOK-A, S01`）：

| 上传槽位 | 内容 | 提示词里 |
|---|---|---|
| 1 | 分镜图（`board_ref`） | `<Picture 1>` |
| 2 | P01 何暖 | `<Picture 2>` → `<Subject 1>` |
| 3 | P02 靳衍 | `<Picture 3>` → `<Subject 2>` |
| 4 | S01 会议室 | `<Picture 4>` → `<Subject 3>` |

## 4. 判据与门禁

判据只有一份实现：`stages/import/h3_prompt.py::lint`。转换（`md2pack`）、门禁（`pack_spec`）、
体检 CLI 三处都调它 —— 任何一处另写正则，就会出现「转换说行、导入说不行」。

| 代号 | 含义 | 档位 | 门禁 |
|---|---|---|---|
| `H3-E01` | 六段缺失 / 顺序错 / 段重复 | 结构 | **SHOT019 阻断** |
| `H3-E02` | 残留 `{{Mixed n}}` | 结构 | SHOT019 |
| `H3-E03` | 出现 `<Video n>` | 结构 | SHOT019 |
| `H3-E04` | `summary` 缺任务类型前缀 / 类型不认识 | 结构 | SHOT019 |
| `H3-E05` | 没有 `<Subject n>` / Subject 编号不连续 | 标签 | **SHOT020 阻断** |
| `H3-E06` | Subject 没引用图 / 图号空号 / 图号超槽位 | 标签 | SHOT020 |
| `H3-E07` | `retention_analysis` 缺行 / 标记词自造 | 标签 | SHOT020 |
| `H3-W01` | 正文没有 `[Shot 1]` | 质量 | SHOT021 告警 |
| `H3-W02` | 第 2 镜起缺 `At MM:SS.mmm` | 质量 | SHOT021 |
| `H3-W03` | `<d>` 里的句子没有句末标点 | 质量 | SHOT021 |
| `H3-W04` | 正文过短（< 每秒 15 字，最低 90 字） | 质量 | SHOT021 |
| `H3-W05` | 有 `<d>` 但没有 `(Sx)` | 质量 | SHOT021 |
| `H3-W06` | 时间戳不早于本镜时长 | 质量 | SHOT021 |
| `H3-W07` | `non_diegetic_music` 留空 | 质量 | SHOT021 |

**为什么结构项阻断、质量项只告警**：结构错了，参考图与主体的绑定就是断的，出片必然要重跑 ——
那是真的花钱；正文写得薄只是「能看但不像」，拦下来会让人去删告警。

## 5. 三条禁令

1. **`{{Mixed n}}` / `{{Picture n}}`**：模型不认。转换层会机械换成 `<Picture n>`，
   但源文件里就不该再写它 —— 换掉的是写法，换不掉已经跑废的成片。
2. **`<Video n>`**：本管线只上传参考图，没有视频参考槽。写了就是悬空标签。
3. **`上传顺序：…` / 「画面：」「运镜：」「音效：」/「禁止：…」**：
   前三类是写给人看的分镜脚手架，会被当正文读；最后一类是负向词，在 cfg=1 的采样下**不起作用**
   （见 `docs/patches/2026-11-06_H3台词烧字幕_patch提案.md`）。想排除什么就正面写。

## 6. 语言口径

**结构标记用英文，正文用项目语言**（中文项目即中文；台词保留原语言在 `<d>` 里）。

官方 `ref-en.txt` 要求六段正文也用英文。本管线**有意偏离**，理由有两条：

1. 台词、资产描述、画风锁都是中文。混排英文正文会让模型在两种语域之间摇摆，
   台词部分尤其明显（中文台词包在英文长文里，语速与停顿会漂）。
2. 实践验证：本仓库 2026-11 的对照实验里，中文正文 + `<d>` 标记的成片口型与配音正常。

判据**不检查正文语种**，只检查结构与标签。要切英文正文，改模板与提示层即可，判据不用动。

## 7. 老项目怎么办

已有项目的 `06-提示词/<ep>/h3_prompts.json` 是旧格式，**不会被自动改写**。

```bash
# 1) 先体检，看有多少镜不合规、具体缺什么
python stages/import/h3_prompt.py --workspace <剧目录>

# 2) 合规的镜不用动；不合规的镜要重写 B 段（按 skill_director §五）
#    重写后重新转换与导入：
python stages/import/md2pack.py --workspace <剧目录>
python stages/import/pack_import.py --pack <剧目录>/pack --workspace <剧目录> --apply
```

**没有「一键升级」**。原因：六段里的 `subject_definitions` 要写清「这张图是谁、保留什么」，
这是判断，不是搬运。机械填模板只会得到一段「结构对、内容空」的提示词 —— 比明着不合格更糟。
