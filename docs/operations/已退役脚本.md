# 已退役脚本与现行入口

2026-11 的重构（见 `docs/BRANCH-ENGINE.md`）删掉了创作层的全部脚本与几个门禁。
但十几份文档还在教人跑它们 —— 照做只会得到 `No such file`，然后 Agent 开始即兴发挥。

**这份表是唯一口径**：遇到本文列出的名字，一律按下表找现行入口；表里没有的，说明它还在。

---

## 一、创作层（整层移除）

现在创作只产出 **Markdown**（`00-创作/02-资产库.md`、`04-导演手册/第NN集.md`），
由 `md2pack.py` 机械转成制作包。**没有任何创作脚本可调**。

| 已退役 | 原来干什么 | 现在怎么做 |
|---|---|---|
| `market_data.py` / `hit_breakdown.py` / `topic_analysis.py` / `hit_selection.py` | 调研、爆款拆解、选题打分 | 交给 LLM，按 `stages/creation/skills/` 的模板写 |
| `genre_formula.py` | 题材公式 | 模板里已内置题材骨架 |
| `script_translate.py` | 多语转译 | LLM 翻译，产出 `--lang` 对应的台词标记 |
| `script_rewrite.py` | 剧本四段法：diagnose / plan / review / build / audience | **方法保留**在 `docs/creation/剧本改编四段法.md`，按它写，不跑命令 |
| `script_continuity.py` | 五锚连续性门禁 | 并入 `stages/import/pack_spec.py` 的校验（`SHOT0xx` 告警） |
| `script_timing_check.py` | 台词时长审计 | 无；按 `docs/creation/台词时长审计口径.md` 人工核字数 |
| `dialogue_gate.py` | 台词逻辑复核 | 无，靠模板约束 + 人工 |
| `prompt_templates.py` | 资产提示词模板 | 模板写作，产物直接进资产库 md |
| `character_design.py` | 角色差异化：plan / check / audit / template | **方法保留**在 `docs/assets/角色差异化设计规范.md`；落点是资产库 md 的 `overrides` 字段 |
| `prompt_gate.py` | 提示词一致性门禁 | 并入 `pack_import.py` 校验 |
