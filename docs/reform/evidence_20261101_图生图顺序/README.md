## 01 / 02 的尺寸为什么不是 9:16

这两张是在**修正前**跑的：当时 `build()` 见到参考图就把布尔节点 `494` 写成 `false`，
开关取 `on_false = 471[2]`（参考图编码出的 latent），于是画幅跟着 ref1 走 ——
ref1 是竖图就出竖版，ref1 是横图就出横版。

**这不是工作流的限制，是我们代码的 bug。** `494` 的标题是「自定义比例」：
- `true` → 取 `on_true = 474 EmptyLatentImage`，尺寸由节点 13 决定（参考图仍作 conditioning）
- `false` → 取 `on_false = 471[2]`，画幅跟随参考图

修正后默认 `true`，`04_9x16_1088x1920.png` 即为修正后的结果（`--aspect 9:16`）。
需要旧行为时用 `--follow-ref-ratio` 显式打开。
