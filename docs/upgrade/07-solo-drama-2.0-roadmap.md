# 07 · SoloDrama 2.0 路线图

> 定位：**一个人就是一个剧组**。从创意到发行版的本地优先创作工作室。
> 铁律：视觉重新设计 / 产品重新组织 / 工程谨慎演进 / 生产能力完整保留。

## 0. 先回答一个问题：这需要「重写」吗？

不需要，也不允许。审计已确认：

- 引擎 13 节点、双份门禁、六态状态机、退出码语义**已在生产里验证过**，动它就是拿稳定换漂亮。
- Studio 的真实问题不是能力缺失，而是**表达缺失**：用户看不到当前阶段、下一步、被拦原因。
- 后端 111 个端点能力远超当前 UI 暴露程度，UI 工作是「组织」不是「补能力」。

唯一必须新增的后端能力：**提示词结构化读写 + 单镜即时校验**（两处，且复用既有规则函数）。

## 1. 阶段总表

| Phase | 主题 | 关键交付 | 通过闸门 | 破坏风险 |
|---|---|---|---|---|
| 0 | 审计 | `docs/upgrade/01–07` | 七份报告互相不矛盾，冲突已记录 | 无（纯读） |
| 1 | 设计系统 | `docs/design/` 六份 + 双主题 Token + `design.html` 样板 | 深浅两套都实拍通过；对比度达标；组件不回归 | **中**：改 CSS 可能影响 22 个视图 |
| 2 | 首页与 IA | 五工作空间导航、首页、项目驾驶舱、通道状态条 | 数据全部来自真实接口；空/错/加载三态齐 | 中：导航重排影响路由 |
| 3 | 创作 + 资产 | 创意工作室、视觉资产工作室 | Markdown 契约不变；资产落点走 `assets_dir()` | 低 |

## 2. Phase 1 范围（本次立即开工）

### 要做的

1. `tokens.css` 重构为**双主题单一来源**：深（Midnight Ink）/ 浅（Warm Paper），保留全部旧变量名做别名（22 个视图零改动即可继续跑）。
2. 语义化命名：`--sd-*` 前缀（surface / text / line / accent / state / type / space / radius / shadow / motion）。
3. 主题解析器：`auto | dark | light`，`localStorage` 记忆，`<head>` 内联脚本防闪白。
4. `design.html` 视觉样板页（真实组件，非图片），含主题切换。
5. 对比度实测（用脚本算 WCAG 比值，不靠眼估）。

### 明确不做的

- 不重写 `app.css` 的 1255 行（只把 72 处硬编码色**映射进 Token**，结构不动）。
- 不改任何视图的 DOM 结构。
- 不改任何后端接口。

## 3. Phase 2 范围（下一阶段）

1. 导航收敛：15 项 → 五个工作空间（创意 / 视觉资产 / 分镜拍摄 / 后期发行 / 制作控制）。
2. 首页：项目海报卡（真实工作区数据）+ 最近任务 + 通道状态 + 成本摘要。
3. 项目驾驶舱：**13 节点可视化为阶段条**，每节点四态（passed/failed/blocked/absent）+ 「下一步唯一推荐动作」。
4. 空/错/加载三态统一（复用 `ui.js` 的 `errorCard` / `skeleton`）。
5. 品牌版本号 → `2.0`。

## 4. 关键路径与顺序约束

```
T1/T2 配色合并（P0）
   └→ 双主题 Token
        └→ design.html 验收
             └→ Phase 2 首页（需要 Token 稳定）
                  └→ Phase 3 创作/资产
                       └→ T5 提示词定源 ──→ T3/T4 结构化读写 ──→ Phase 4 分镜
                                                                  └→ Phase 5 后期发行
```

硬约束：

- **T5（提示词双份定源）必须在 Phase 4 开工前完成**，否则写回可能落到错副本，表现为「改了没生效」，极难查。
- **Phase 2 的驾驶舱必须先于 Phase 4**：分镜页的「为什么不能出片」依赖节点状态语义。
- Phase 5 不得为了「一键发行」新增第二个导出实现；`release_export.py --all --apply` 是唯一出口。

## 5. 验收口径（每阶段都要能回答）

| 维度 | 判据 | 证据形式 |
|---|---|---|
| 真实数据 | 页面上的每个数字都能追到一个接口或文件 | 接口名 + 字段 |
| 无假按钮 | 每个可点元素有真实行为或明确禁用理由 | 点击清单 |
| 门禁不降 | 只读模式下写端点返回 423；计费需确认 | curl 实测 |
| 契约不变 | 制作包/资产/发行落点零变化 | sha256 / 目录 diff |
| 测试 | 不删测试、不降断言 | 命令 + 通过数 |
| 视觉 | 深浅双主题 + 移动端 | 截图 |

## 6. 风险登记

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 改 CSS 后某页视觉错乱 | 高 | 中 | 旧变量全保留别名；逐页截图比对 |
| 提示词写回写错副本 | 中 | **高** | T5 先定源 + 写前备份 + 干跑 |
| 导航重排导致路由 404 | 中 | 中 | 旧 hash 路由全部保留重定向 |
| 用户工作区被误改 | 低 | **极高** | 只读优先、干跑、备份、二次确认 |
| 误把「已移除能力」做成页面 | 中 | 中 | T12 清单前置；评审时逐条对照 |
