## 三个「看起来是债、其实不是」的项（防止误改）

1. **零构建前端**：不是技术落后，是刻意的（无 npm、无 CI 打包、改完刷新即生效）。引入构建链反而会丢掉 `_FreshStatic` + 版本串这套防缓存修复。
2. **`web/` 不 import `stages/`**：不是重复代码，是进程级解耦。任何「抽个公共包让两边共用」的重构都是倒退。
3. **`--fs-11` 之类旧变量名**：不是没改干净，是保持 22 个视图不崩。可以并存，不可暴力重命名。
