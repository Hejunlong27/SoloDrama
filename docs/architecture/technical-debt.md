## 三个「看起来是债、其实不是」

1. **零构建前端** —— 刻意选择。引入构建链会丢掉 `_FreshStatic` + 版本串这层防缓存修复。
2. **Web 不 import 引擎** —— 进程级解耦。任何「抽公共包两边共用」都是倒退。
3. **旧 Token 名（`--fs-11` 等）** —— 保 22 个视图不崩。可并存，不可暴力重命名。
