# 产线「对账关卡」：把 26 个坑变成固定检查（2026-10-18）

> 来源：`SoloDrama_踩坑清单_2026-10-18.md`（40 集实跑复盘）+ `2026-10-18_短剧产线补丁清单.md`（逐条 patch）。
>
> **这份文档的立场**：那 26 个坑里 **18 个不是「算错」，而是「没人对账」** ——
> 文件对不对得上字典、计划对不对得上成片、成本对不对得上步数、时间轴对不对得上语音。
> 因此本清单不再重复「现象/根因」，而是把每条坑**映射到一个可执行的关卡**：
> 能机器判的进「自动对账」，机器判不了的进「人工对账（交付前必答）」。
>
> 用法：**新项目开跑前读一遍「自动对账」清单，确认对应脚本在位；每集交付前过一遍「人工对账」三问。**

## 一、自动对账（机器可判 · 命令可直接抄）

| # | 坑 | 对账对象 | 命令 / 脚本 | 判据 |
|---|---|---|---|---|
| A1 | 资产在磁盘但没登记进 `characters.json` | 文件 ↔ 字典 | `drama.py refs --apply` / `preflight` | 双向校验：磁盘有 + 字典缺 → **自动补写并记日志**；字典有 + 磁盘缺 → 退出码 2 |
| A2 | `refs` 的 key 被当文件路径 | 契约 ↔ 实现 | `ingest_check.py --ep epNN` | `refs: char_01`（key）与 `refs: refs_h3/x.jpg`（路径）**都要通过** |
| A3 | 槽位数只数角色图 | 契约 ↔ 实现 | `ingest_check.py --ep epNN` | 「2 角色 + 1 场景」且 `<Picture 3>` **不得报缺图** |
| B1 | 批次目录按秒命名，同秒并发抢 `state.json.tmp` | 并发 ↔ 目录唯一性 | `ls 07-成片/`（或 `output/`） | 目录数 = 并发段数，且**无 `Errno 13`** |
| B2 | 孤儿任务占满车道 → 421 | 重试语义 | `drama.py video status <批次>` | 421 按**可重试**处理（不退避到降并发）；杀进程后先等一个心跳周期 |
| C1 | LoRA 4 步、节点却跑 10 步 | 成本 ↔ 步数 | `drama.py cost --checkpoint` | 单段币数落在 `8 + 2.18 × 秒` 附近（4 步口径）；偏差 >10% 即查节点步数 |
| C2 | 每镜帧数补齐 → 系统性超时长 | 计划 ↔ 成片 | `ffprobe` 母版 + 分镜 md 时长求和 | 排片公式：`计划 = 目标 − 0.39×镜数 − 封面时长`；连续 5 集成片**极差 <1 秒** |
| C3 | 镜长下限与时长上限打架 | 可行性 ↔ 排片 | 排片前置算式 | `n_min = ceil(目标/7)`、`n_max = floor(目标/5)`；越界**排片前**报错，不等渲染 |
| D2 | 分镜 md 与成片时间轴不一致 | md ↔ 成片 | `|Σ(成片段时长) − Σ(md 计划)| ` | 差 > **1.5 秒** 即判不一致 → 首选重出片，次选用成片真实时间窗重排字幕 |
| E1 | VAD 重映射时间戳 | 时间轴 ↔ 真值 | 字幕对齐链路 | **必须 `vad_filter=False`**；同素材开/关 VAD 末句时间差应 <0.1 秒 |
| E2 | faster-whisper 与新版 PyAV 不兼容 | 依赖 ↔ 接口 | 识别前置 | 先用 ffmpeg 转 16k 单声道 WAV，再传 numpy 数组（不让它解码容器） |
| E6 | 同镜两句字幕重叠倒挂 | 字幕 ↔ 字幕 | 出片前全局检查 | 倒挂数 **= 0** 才可交付 |
| F1 | 参考图编号与角色卡数组顺序不一致 | key ↔ 数组下标 | 资产加载校验 | 一律**按 key 查表**，不允许数组下标对应；key 唯一且无空洞 |
| F2 | 四视图设定板未切分就送封面引擎 | 素材版式 ↔ 用途 | 封面送图前 | 先裁最左特写面板（`crop=592:1344:0:0` 类），资产入库时标记版式类型 |
| G1 | 子进程弹控制台窗口 | 进程 ↔ 会话 | 所有 `subprocess.run/Popen` | 加 `creationflags=0x08000000`；常驻循环用 `pythonw.exe` |
| G3 | 同一凭据多路径 realpath 相同 → 成本三倍虚增 | 账本 ↔ 实体 | `drama.py cost` / 控制台 `inventory.py` | 统计前按 **realpath 去重**；账本按 `taskId` 去重，不按文件累加 |
| G5 | 识别结果未缓存 → 改样式要重跑全流程 | 中间产物 ↔ 复用 | 字幕链路 | 词级时间戳**按集缓存** `epNN.json`；改样式只重跑合成+编码 |
| **发行** | 发行资料（封面档位 / 版权资料 4+4）漏项 | 发行包 ↔ 清单 | `release_check.py --workspace <ws>` | 退出码 **2 = 不齐**；封面 9x16 + 3x4 必备，版权资料 4+4 不缺号、长边 ≥1200 |

### 建议固化为「一集一出」的自动对账链（全零费用）

```powershell
python stages/production/scripts/drama.py preflight                                  # A1 资产双向校验
python stages/production/scripts/ingest_check.py --workspace <ws> --ep epNN          # A2 A3 入门口禁
python stages/production/scripts/script_timing_check.py --workspace <ws> --ep epNN   # 台词时长审计
python stages/production/scripts/subtitle.py --workspace <ws> --ep epNN              # E1/E6 时间轴（内部断言）
python stages/production/scripts/drama.py cost --checkpoint                          # C1/G3 成本对账
python stages/production/scripts/release_check.py --workspace <ws>                   # 发行资料（发行前）
```

## 二、人工对账（机器判不了 · 交付前必答三问）

| # | 坑 | 必答问题 | 不通过的处置 |
|---|---|---|---|
| B3 | 静态奇偶分账号 → 一方空转 | 本集是**共享队列按空出车道领活**，还是静态切分？ | 改共享队列；否则总时长被最慢账号拖住 |
| B4 | 巡检间隔过长 → 集间空转 | 交付→派发的间隔是多少？ | 目标 ≤90 秒（实测可到 31 秒） |
| B5 | 看门狗静默死亡 | **心跳文件**是否每分钟推进？ | 心跳 >5 分钟未更新即告警；守护须独立于会话 |
| C2 | 成片时长 vs 计划 | 本集成片时长落在 70–73 秒内吗？ | 超了调排片公式，不要事后裁片 |
| D1 | 母版没有封面首帧 | 母版**第 1 帧**是封面吗？音画时长差 <0.05s？ | 拼接时前置 1.5 秒封面，字幕整体后移 |
| E3 | 西语数词不归一 | 识别侧与稿件侧都过 `numberize()` 了吗？ | 否则「noventa y siete」相似度为 0，只能回退估算 |
| E4 | 匹配窗口有容差 → 字幕吸附到相邻镜 | 是否**严格限制在本镜内**？ | 越界候选按秒扣分（−0.35/秒）；宁可回退也不跨镜 |
| E5 | 断句落在虚词上 / 折成三行 | 断点有没有落在虚词？每条 ≤72 字符？ | 落在虚词上回退一个词；末尾 30% 有标点则优先在标点后断 |
| G2 | 模型下载被代理拦截 | `HF_ENDPOINT=https://hf-mirror.com` 已设？模型就位后设 `HF_HUB_OFFLINE=1`？ | 否则启动探活反复失败 |
| G4 | 余额/任务数瞬时为 0 被误判故障 | 判断健康是否用了**心跳推进**与**交付目录文件数增长**这两个可靠指标？ | 不要用 `currentTaskCounts == 0` 判健康 |
| **发行** | 封面「抓马度」不足 | 六抓手命中 ≥5/6？`cover_spec.json` 的 `reviewer` 已填？ | 按 `docs/distribution/发行资料清单.md` §3.6 反例清单打回重做 |
| **发行** | 版权资料不可辨认 | 八张图的**任务 ID / 时间戳肉眼可读**（且未打码）吗？外部人能独立读懂吗？ | 重截；每张都要能脱离上下文自证 |

## 五、量化回归基线（对账用真值）

| 指标 | 基线值 |
|---|---|
| 规模 | 40 集 / 483 镜 / 3,523 秒 |
| 单段出片 | ≤2 分钟（5 车道并行） |
| 单集出片 | 7–11 分钟（派发到交付，含拼接） |
| 字幕 + 放大 | ≈20 秒/集（识别 10s + 编码 9s） |
| 单段成本 | 30 币（4 步 LoRA 对齐后） |
| 单集体积 | 1080×1920 h264 ≈ 60–100 MB |
| 交付质检 | 40/40 首帧为封面、音轨齐全、时间倒挂 0 |

> 任何一项偏离基线 >20%，按 §一 逐条对账，不要先怀疑随机性。
