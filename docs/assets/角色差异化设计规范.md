# 角色差异化设计规范（同一部剧里，谁都不该长得像谁）

- 版本：v1.0 ｜ 日期：2026-10-20
- 地位：**角色形象设计与人物资产提示词的单一真源。** 与 Skill 说明冲突时，以本文档 + 仓库代码为准。
- 可执行部分：`stages/assets/scripts/character_design.py`（`plan` / `check` / `audit`）+ 28 例离线测试
- 上游依赖：`docs/styles/画风三轨规范.md`（画风决定资产规格）；下游消费：`stages/assets/scripts/prompt_templates.py`、`gen_char_assets.py`、`asset_md.py`

---

## 零、这份规范要解决什么

短剧的**人物图撞脸**，通常不是模型能力问题，而是**提示词把差异抹平了**。表现出来是：
三个女性角色换掉衣服就成了同一个人；观众记不住反派；主角与配角站在一起没有辨识度。

更隐蔽的代价是**返工**：一次 40 集的剧要出 15–25 张人物图，撞脸意味着整批重画，
每张 6–7 RH 币，返工一轮就是几百币（此前的成本台账已经记录过一次「提示词缺陷多花 269 币」）。

本规范的目标不是「画得更好看」，而是把「**不同角色必须可被区分**」变成一条可分配、可校验的工程约束。

## 一、五个根因（都能在真实资产提示词里看到）

| # | 根因 | 现场证据（实测样本） | 后果 |
|---|---|---|---|
| 1 | **统一风格锚** | 同一部剧 10 个角色，开头 30 字风格串逐字相同（写实 3D CG / 暖调高饱和 / PBR / 次表面散射） | 风格 token 一致时，模型对「脸」的自由度最大 → 回落到训练均值脸 |
| 2 | **统一构图与背景** | 10 人全是「半身胸像 + 中灰背景 + 柔光打面」 | 同一构图反复喂，模型倾向复用同一张脸 |
| 3 | **关键维度缺失** | 同一部剧 **10 人里只有 2 人写了脸型**；另一部剧 **5 人里 0 人写脸型** | 缺的维度 = 交给模型自由发挥 = 全员默认脸 |
| 4 | **维度趋同** | 同一部剧 **7/10 人是「浓眉」**、4/10 是「短发」 | 眉形是最强的身份线索，全员浓眉等于磨掉这条线索 |
| 5 | **无识别锚** | 同一部剧 **3/10 人没有任何可指认标记**（无痣/疤/眼镜/耳饰/旧物） | 模型画不出「气质」，只画得出「一颗痣」；没有锚就没有身份 |

> 结论：**「写得模糊」比「写得不好」更致命。** 资产卡里「气质清冷、面容精致」这类词，
> 在模型里指向的是同一批高频脸——写十个人等于写一个人。

## 二、六维签名：把「长相」拆成可分配的参数

| 维 | 考察什么 | 可画写法（✅） | 不可画写法（❌） |
|---|---|---|---|
| **D1 骨相** | 脸型几何 / 中庭比例 / 下颌角 / 颧弓 / 眉骨 | 「方脸，下颌角接近 110°、下颌体厚；中庭适中；颧骨平缓但颧弓宽」 | 「五官立体」「轮廓分明」 |
| **D2 发型轮廓** | 长度 × 体积 × 发际线 × 边缘 | 「3mm 推剪寸头，发际线与颅骨形状清晰」 | 「利落的发型」 |
| **D3 眉眼结构** | 眉形 / 眉距 / 眼型 / 眼裂高度 / 眼距 | 「眉形平直粗、眉尾短；眼裂中等、上眼睑微垂」 | 「眼神凌厉」「眉眼精致」 |
| **D4 色彩签名** | 主色相 + 明度 / 饱和度 + 一处撞色落点 | 「主色朱砂（#7B3C32），撞色 #388A6C 只出现在领口滚边」 | 「深色系穿搭」 |
| **D5 材质织物** | 织物种类 + 垂坠 / 反光行为 | 「精纺羊毛，垂坠挺括、表面哑光、折线利落」 | 「高级面料的衣服」 |
| **D6 识别锚** | 一处**非对称**、可指认、跨镜不变的标记 | 「右眉尾一道浅白旧疤（约 1.5cm，断开眉毛）」 | 「对称双眼」「五官对称」 |

**为什么是这六维**：D1–D3 决定「像谁」，且不随服装变化；D4–D5 决定「哪个阶层/职业」；
D6 是**唯一能在三米外被指认的特征**。全部角色在这六维上被分配完毕，差异是**构造出来的**，
不依赖写作者的灵感。

**实现方式**：按人群桶（掌控者 / 隐忍者 / 天真者 / 闯入者 / 算计者 / 执行者 / 长者 / 市井者 / 江湖者 / 病态者）
定候选集 → 逐角色取「离已选角色最远」的骨相（最大最小距离贪心）→ 同阵营共享色相但拉开明度。

## 三、剧组级配额：六条硬规则

`python stages/assets/scripts/character_design.py check --bible 04-资产/design/character-bible.json`
—— 不过即**退出码 2**，可挂进交付前自检。

| # | 规则 | 判据 | 为什么这样定 |
|---|---|---|---|
| **R1** | 任意两角色面部距离 ≥ 0.50 | 七槽签名（脸型/中庭/下颌/眉/眼/鼻/唇）至少 4 槽不同 | 低于 0.5 = 共用骨相档案，换装即成同一人 |
| **R2** | 主角 vs 任一其他角色 ≥ 0.625 | 至少 5 槽不同 | 主角与最近配角最容易「撞成双胞胎」 |
| **R3** | 不同阵营色相间隔 ≥ 30°；中性色对明度差 ≥ 0.10 | 色相环最短弧 | 观众靠色块分辨阵营；同阵营同色同明度 = 分不清谁是谁 |
| **R4** | 识别锚全局唯一 | 不得两人共用同一处标记 | 「两颗同位置泪痣」比没有锚更糟（观众会以为是同一人） |
| **R5** | 主演 / 配演发型不重复 | 群演可复用，但要 warning | 发型是剪影层唯一特征 |
| **R6** | 文案不得含评价性美颜词 | 见 §五 禁用表 | 评价词 = 把差异交回给模型默认值 |

**同阵营的例外**：家族成员**应当**看起来像一家人（共享色相、相近骨相）。
规范不禁止这一点，但要求 **明度差 ≥ 0.10**（深藏青 / 中灰蓝 / 浅灰蓝），
并用识别锚把两个人彻底分开。

## 四、提示词三件套（真正让差异落地的三句话）

一张人物图能不能守住差异，取决于提示词里有没有这三件东西：

### ① 识别锚前置（放在最前，先于风格）

```
【唯一识别锚｜先读这一条】右眉尾一道浅白旧疤（约 1.5cm，断开眉毛）。
```

- 放在**风格串之后、形象描述之前**。模型对 prompt 前段的注意力最高。
- 锚必须**非对称**：「对称双眼」「五官对称」不构成锚（它描述的是没有特征）。
- 锚必须**跨镜可见**：痣/疤/眼镜/耳饰/戒指/旧表/钥匙串；不能是「说话时挑眉」。

### ② 反默认（明确写出「不要哪种脸」）

```
排除标准网红脸（削尖下颌＋放大眼裂＋垫高鼻梁＋无毛孔磨皮）、韩式平眉、烤瓷牙反光、
左右绝对对称的脸；不把下颌画圆；五官不混入欧美高鼻骨与深眼窝。
```

- 只写「要什么」时，模型用默认值填空；把「不要什么」写具体，差异才守得住。
- 反默认要**跟着骨相走**：方颌角色写「不把下颌磨圆成鹅蛋脸」，短圆脸写「不把脸拉长」。
- 反默认要**跟着族裔走**：东亚角色不写「深眼窝/鹰钩鼻」（否则同一段提示词自相矛盾）。

### ③ 差异对照（把「另一个人长什么样」也写进来）

```
同剧 申雅莱（财阀大小姐）为心形尖颌、中分长直；本角色为六边棱角、高蓬松马尾。
两人同框时发型、眉形与主色必须可区分。
```

- 这是**性价比最高的一句**：它在同一段上下文里给了模型一个「对照锚」，
  比任何形容词都更能阻止两人共用一张脸。
- 对照对象选「与本角色最像的那位」（脚本自动挑最近邻），不是随便挑一个。

## 五、语言纪律：禁用评价词，改用几何词

| 禁用（模型默认值触发器） | 替换为（可画参数） |
|---|---|
| 俊美 / 俊朗 / 绝美 / 惊艳 / 气质出众 / 五官精致 / 面容精致 | 脸型几何 + 中庭比例 + 下颌角 + 眉形眉距 + 眼型眼裂 + 鼻骨鼻翼 + 唇厚唇峰 |
| 白皙无瑕 / 完美无瑕 / 皮肤通透 | 肤色区间 + 毛孔 + 细纹 + 晒斑 +（按年龄分层的）手背与颈部纹理 |
| 身材修长 / 纤细姣好 | 肩线（平肩/溜肩）+ 颈长 + 骨点（锁骨/腕骨）+ 站姿重心 |
| 高级感 / 有质感 | 织物种类 + 垂坠行为 + 反光行为 + 使用痕迹 |

**年龄纹理必须分层**（最容易忽略的一条）：18/28/38/52/65 岁不能用同一句
「皮肤细腻、无瑕」。实测提示词里 90% 的角色皮肤被写成 25 岁，
这是「全员一张脸」的第二大来源。

## 六、接入工作流

### 6.1 顺序（不可颠倒）

```
① drama.py style（画风三轨）→ ② drama.py models（通道）
→ ③ character_design plan（**本规范**：六维签名 + 提示词三件套）
→ ④ 出图（本地 ComfyUI / RunningHub）→ ⑤ 分镜 → ⑥ halfcheck → ⑦ 出片
```

**必须在出图之前**：画风锁定后、任何一张人物图生成之前。出图之后再改骨相 = 已产出素材全部作废。

### 6.2 命令

```bash
# 名册模板（只需写身份与性格，视觉参数由脚本分配）
python stages/assets/scripts/character_design.py template --out 04-资产/design/roster.json

# 生成：角色圣经 + 三件套提示词 + 差异矩阵
python stages/assets/scripts/character_design.py plan --roster 04-资产/design/roster.json \
       --out 04-资产/design

# 门禁：六条硬规则（退出码 2 = 不过）
python stages/assets/scripts/character_design.py check \
       --bible 04-资产/design/character-bible.json
```

### 6.3 产物与去向

| 产物 | 去向 | 说明 |
|---|---|---|
| `character-bible.json` | `04-资产/design/` | 机器真源（六维签名 + 差异矩阵），`check` 的输入 |
| `角色差异化矩阵.md` | `04-资产/design/` | 人读：逐角色签名 + 两两对照 + 规则判定 |
| `资产提示词_角色段.md` | 并入 `资产提示词.md` 的「一、角色资产库」 | **可直接**喂 `gen_char_assets.py` / `asset_md.py` |
| `prompts/char/CHxx_*_设定板.txt` | `04-资产/design/prompts/char/` | 横版设定板（含三视图 + 面部特写 + 色卡） |
| `prompts/char/CHxx_*_主卡.txt` | 同上 | 正面 3/4 全身主卡（3D 轨首帧锚点用） |
| `prompts/char/CHxx_*_定妆照.txt` | 同上 | 半身胸像（选角 / 只出脸时用） |

> ⚠️ 出图产物仍落 **`04-资产/{characters,scenes,props}`**（总纲 §3.7），
> 设计文件落 `04-资产/design/`，两者不混。

### 6.4 名册怎么写

```json
{
  "world": "当代韩国首尔·财阀高中",
  "region": "east_asian",
  "style_lock": "3D-manhua-cel",
  "style_anchor": "电影级写实 3D CG 渲染，实拍级质感，PBR 物理材质",
  "seed": "solodrama",
  "characters": [
    {"name": "楚湘", "gender": "f", "age": 18, "tier": "lead",
     "identity": "转校生", "faction": "外来者",
     "persona": ["野性", "不驯"],
     "overrides": {"anchor": "磨损编织绳", "hair": "高蓬松马尾"}}
  ]
}
```

- **必填**：`name` / `gender` / `age` / `identity` / `tier`（lead/support/minor）/ `persona` / `faction`
- `region`：`east_asian` / `latam_mestizo` / `western`（决定肤色、毛发与五官倾向）
- `overrides`：只在前述分配不合意时用，可选 `face` / `hair` / `fabric` / `anchor`（按中文名或 ID）；
  **覆盖也会被 `check` 校验**——不要用它绕过规则
- `world` 与 `style_anchor` **不要互相矛盾**（曾出现 `world=财阀高中` 却把 `style_anchor` 写成「当代中国都市」）

## 七、体检老项目（已出图 / 已有资产提示词）

```bash
python stages/assets/scripts/character_design.py audit --md 资产提示词.md --out 同质化体检.md
```

输出：逐角色签名表 + 冲突对（≥3 维撞车）+ **维度覆盖率**（哪个维度几个人没写）+ 缺识别锚名单。

实测两例（均为真实在跑项目，已匿名）：

| 样本 | 角色数 | 写出脸型 | 浓眉 | 无识别锚 | 结论 |
|---|---|---|---|---|---|
| A（西语剧） | 10 | **2** | **7** | **3** | 8 人脸型缺失、3 人无锚 → 模型必然收敛 |
| B（校园剧） | 5 | **0** | 3 | **3** | 全员无脸型描述 → 靠服装区分，换装即换人 |

> 体检是**词表启发式**：只认显式写出的特征词。命中率低本身就是信号——
> 「气质清冷」这类写法不会命中任何维度，它也不该命中。

## 八、验收清单（交付前自问五句）

1. **脸型写了吗？** 每个角色都有一句「脸型 + 下颌/颧骨」的几何描述，不是「轮廓分明」。
2. **两个人换掉衣服还认得出吗？** 拿掉服装与场景，只看脸与锚，能不能说出这是谁。
3. **每个角色有唯一锚吗？** 一处、非对称、跨镜可见，且全剧不重复。
4. **同框能不能分开？** 主色、发型、眉形三者至少两项不同（同阵营另加明度差）。
5. **年龄写进皮肤了吗？** 18 岁与 52 岁的皮肤/颈纹/手背描述必须是两句不同的话。

## 十、已知局限

1. **面部距离是粗粒度指标**：同一骨相档案内不区分程度，它的作用是**否决**（不许两人共用档案），
   不是精细相似度。真正的强保障来自「骨相档案 + 发型 + 锚 + 色签名」四条同时不同。
2. **词库是东亚 / 拉美 / 西方三套**，其他族裔需要扩 `REGION`（含 `repl` 改口表）。
3. **不做美学判断**：脚本保证「不像」，不保证「好看」；选角与审美仍需人工过一眼定妆照。
4. **不替代剧本**：名册里的身份/年龄/阵营必须来自剧本，脚本只分配视觉参数，不发明人设。
5. **未覆盖**：动态识别锚（走路姿态、口音、常用手势）——这些属于表演层，不属于资产卡。
