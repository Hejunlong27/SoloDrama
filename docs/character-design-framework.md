# 角色设计流程 v2：框架 + 美学（framework / aesthetic 分工）

- 版本：v2.0 ｜ 日期：2026-10-30
- 起因：v1 用「7 个骨相槽位分别取值再拼接」生成角色描述，实测产出普遍"丑且同质化"。
- 本文档只定义**框架与验收**，**不枚举具体长相**（具体长相属于美学层，由写手/模型逐角色撰写）。

---

## 一、v1 为什么失败（三个机制性原因）

| # | 机制 | 后果 |
|---|---|---|
| 1 | **槽位独立、无审美平衡** | 脸型/中庭/下颌/眉/眼/鼻/唇 七项各自取值，可以合法组合出「颊凹 + 中庭长 + 眉头低 + 上睑薄 + 鼻尖下垂 + 唇角下压」——七个负向特征叠一张脸，必然苦相、显老 |
| 2 | **只有几何、没有气质** | 描述是法医式测量（"眼裂高度小""颧弓不外扩"），没有肤色质感、没有光感、没有神态，出图只能得到"参数正确但没魅力"的脸 |
| 3 | **跨剧同质化** | 配色槽位 `_hue_slots()` 对所有项目用同一固定顺序；脸型选择被 `persona_bucket` 的偏好集合强约束。同题材两剧，阵营数相同则配色几乎一样、脸型从同一小批里挑 |

一句话：v1 把「好看」当成了「参数不冲突」，但好看是**整体协调 + 有记忆点**，不是参数合法。

---

## 二、两层分工（核心）

```
框架层（可自动化、可门禁）        美学层（逐角色撰写、不可枚举）
─────────────────────────       ─────────────────────────────
角色定位：tier / 年龄 / 性别 / 阵营    一段 120–200 字的美学 brief：
识别锚：1 个，必须可指认                   骨相基调 → 五官气质 → 皮肤与光 → 整体气质 → 上镜条件
色彩纪律：主色 / 撞色 / 撞色出现位置
服饰阶级：面料 / 剪裁 / 鞋包
多样性约束：同剧不撞脸 / 不撞色 / 不撞发型
审美配比：负向特征 ≤1 项
```

**框架层管"不能错"，美学层管"好看"。** 前者可以脚本校验，后者必须人/模型写。

---

## 三、框架层：字段与硬约束

### 3.1 必填字段

| 字段 | 说明 | 校验 |
|---|---|---|
| `tier` | lead / support / cameo | 枚举 |
| `age` / `gender` | 角色实际年龄与性别 | 数值 + 枚举 |
| `faction` | 阵营（决定色相槽位） | 同剧唯一分配 |
| `anchor` | **识别锚，恰好 1 个**：一个可指认、可复现的外形特征 | 全剧唯一，且不与他人重复 |
| `palette` | 主色 hex + 撞色 hex + 撞色出现位置（袖口/领口/包/鞋…） | 同剧主色色相差 ≥24° |
| `garment` | 上装 / 下装 / 鞋 / 配件 + 面料 | 面料与角色阶级匹配 |
| `aesthetic_brief` | 见 §四 | 非空、120–200 字、负向词 ≤1 |

### 3.2 审美配比（新增硬约束，直接解决"丑"）

把描述性词汇分为三类，**同一个角色里负向词不得超过 1 个**：

| 类型 | 例词 | 上限 |
|---|---|---|
| 负向（显苦/显老/显凶） | 凹陷、下垂、下压、偏薄、内收过度、眉头低、唇角下压、法令纹深 | **≤1** |
| 中性（骨相事实） | 鹅蛋、方圆、中庭适中、下颌线清晰 | 不限 |
| 正向（显好看/显气质） | 饱满、干净、柔和、有光泽、眼尾微扬、唇形饱满、皮肤通透 | **≥2** |

理由：辨识度只需要 1 个"不完美"（那正是锚），其余应当服务于"好看"。

### 3.3 多样性约束（同剧）

- **脸型**：任意两角色的骨相基调不得属于同一大类（长椭圆 / 短圆 / 方颌 / 菱形 / 心形 各至多 2 人）；
- **发型**：不得重复轮廓（高马尾 / 低盘 / 齐刘海 / 寸头 / 背头 / 中分长直 …）；
- **配色**：主色色相差 ≥24°，撞色不得同色系；
- **年龄感**：同年龄段（±3 岁）的角色不得有 ≥2 个同气质类型。

### 3.4 跨剧多样性（v1 完全缺失）

- 项目 `seed` 必须参与**一级排序**，而不是只在平局时决定次序；
- 维护一份跨项目「已用组合」台账（骨相 + 发型 + 主色），新项目优先避开近 3 部剧用过的组合；
- 配色槽位需按项目 seed 做旋转偏移，不再对所有项目用同一顺序。

## 四、美学层：brief 的写法

### 4.1 五要素（按顺序写，缺一不可）

1. **骨相基调**——一句话定脸型大类 + 骨相强弱（例：「干净的小鹅蛋脸，颧骨不高，下颌线柔和地收进去」）
2. **五官气质**——眼、鼻、唇各一句，重在**神态**而非尺寸（例：「眼睛偏圆，眼尾微微上扬，笑起来有卧蚕」）
3. **皮肤与光**——质感必须真实可拍（例：「在窗边自然光下能看到细小绒毛和一点雀斑」）
4. **整体气质**——两个词以内的定调 + 一句"不是什么"（例：「克制的锋利，不甜」）
5. **上镜条件**——镜头下的表现（例：「侧脸比正脸更上镜，低头时睫毛在颧骨上投影」）

### 4.2 禁止写法

| 禁止 | 原因 |
|---|---|
| 纯尺寸罗列（"眼裂高度小""鼻翼宽 1.2cm"） | 参数正确但不产生魅力 |
| 负向词堆叠（≥2 个） | 直接导致苦相/显老 |
| 形容词空转（"惊艳""绝美""气质出众"） | 不可画面化，模型无法执行 |
| 网络审美套话（"初恋脸""高级脸""建模脸"） | 无具体指向，等于没写 |

### 4.3 示范（同一角色，v1 vs v2）

**v1（拼接式，实测产出）**
> 削瘦刻相：瘦削颊凹、中庭偏长、下颌角明显、细眉眉头低、浅眼窝上睑薄、细鼻梁鼻尖下垂、薄唇唇角下压。

**v2（框架 + 美学）**
> 干净的小鹅蛋脸，颧骨不高，下颌线柔和地收进去，脸颊有一点没褪干净的软肉；眼睛偏圆，眼尾微微上扬，不笑时也像在忍笑；鼻梁细但鼻头有一点肉，唇形饱满、唇峰不锐。皮肤是那种在窗边自然光下能看到细小绒毛和浅淡雀斑的真实感，颧骨有自然红晕。整体是克制的锋利，不甜、不柔弱。侧脸比正脸更上镜，低头时睫毛会在颧骨上投一道影。
> 识别锚：下唇左侧一道 8mm 竖向细疤（唯一的不完美，其余服务于好看）。

差别：v1 有 7 个负向特征、0 个正向；v2 有 1 个负向（疤，且是锚）、6 个正向。

## 五、验收门禁（可自动化）

`release_check` 之外新增 `character_check`，逐角色校验：

| 检查 | 判据 | 级别 |
|---|---|---|
| E1 负向词计数 | ≤1 | FAIL |
| E2 正向词计数 | ≥2 | FAIL |
| E3 锚唯一 | 全剧恰好 1 个，且不与他人重复 | FAIL |
| E4 brief 长度 | 120–200 字 | WARN |
| E5 五要素齐备 | 骨相/五官/皮肤/气质/上镜 各命中 | WARN |
| E6 同剧脸型大类 | 同类 ≤2 人 | FAIL |
| E7 同剧主色色相差 | ≥24° | FAIL |
| E8 跨剧重复 | 与近 3 部剧的（骨相+发型+主色）组合不重复 | WARN |

## 六、引擎改造清单（v1 → v2）

| 文件 | 改动 |
|---|---|
| `stages/assets/scripts/character_design.py` | ① `FACE_GEOM` 的 `slots` 不再直接拼进描述，改为输出 `skeleton_class`（脸型大类）+ 候选 2–3 个；② 新增 `aesthetic_brief` 空位（由写手/模型填）；③ 新增 §3.2 审美配比自检；④ `_hue_slots()` 接入项目 seed 旋转 |
| `stages/assets/scripts/asset_md.py` | 资产提示词从「读 slots 拼接」改为「读 aesthetic_brief + 框架字段」 |
| 新增 `stages/assets/scripts/character_check.py` | 实现 §五 的 E1–E8 |
| `docs/character-design-framework.md` | 本文档，作为 v2 的单一真源 |

**不建议**在引擎里枚举"好看长什么样"——那会把 v1 的错再犯一次。引擎只保证**约束成立**，美感由 brief 承担。
