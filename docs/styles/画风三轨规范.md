## 零、为什么画风必须「任务开始前」确认

画风决定后面**一切**规格，而且**不可事后更换**：

| 画风决定 | 3D 漫剧 | 2D 动画 | 真人写实 |
|---|---|---|---|
| 资产数量 | 角色**主卡 + 三视图**；场景**主卡 + 辅卡** | 角色卡 ×1；场景卡 ×1 | 角色卡 ×1；场景卡 ×1 |
| 单镜时长 | 6–10s（动作 4–6s） | 4–10s | **5–15 整数秒** |
| 旁白字数上限 | 28 / 32 / 36 | 32 / 36 / 40 | 60 / 70 / 80 |
| 首帧锚点 | **强制**，且**角度必须匹配** | 可选 | 单格干净图 |
| 分镜拓扑 | 逐镜 | 逐镜 | **强制 1 片段 = 1 张三格时间分镜** |
| 交付终点 | 无旁白成片 + 独立旁白包 | **旁白交接（不出成片）** | 成片 + 旁白 + 可选字幕 |

> 换画风 = 已产出的资产、分镜、提示词**全部作废**。所以门禁放在最前面，与「通道确认」并列。

```powershell
python stages/production/scripts/drama.py style status         # 先看状态
python stages/production/scripts/drama.py style set 3d_manhua --sub-mode guoman-3d-render
python stages/production/scripts/drama.py style set 2d_animation --sub-mode guoman-webtoon
python stages/production/scripts/drama.py style set live_action
```

未确认时任何生成动作会被拦下，**退出码 4**。确认单落 `<工作区>/style-plan.json`。

## 一、三轨总览

### 1.1 `3d_manhua` —— 3D 漫剧半解说短剧

- `visual_style_lock = 3D-manhua-cel`（3 个子模式互斥，一集只用一个）
- 资产：每主要角色 **1 主卡（正面 3/4）+ 1 三视图（正/侧/背）**；每主要场景 **1 主卡 + 1 辅卡**；道具卡 ≤1
- 单镜 6–10s；战斗/快切 4–6s；**上限 10s**
- 重置锚周期：**主角 4 镜 / 配角 6 镜 / 场景 5 镜**
- 首帧锚点**强制**（`opening_frame_image` 必传，**禁止纯文字生视频**），且 **`first_frame_angle_match` 必须为 true**
- 交付：无旁白成片直拼 + 独立旁白包 + 实测时间表（**不混音**）

**子模式与风格块（每条图/视频 prompt 必带，逐字）**

| 子模式 | 键 | 风格块（逐字复制） |
|---|---|---|
| 国漫 3D 渲染流（默认） | `guoman-3d-render` | `3D rendered, Chinese-animation manhua-cel look, clean dark outlines on top of 3D shading, soft PBR materials with non-photoreal finish, dynamic manhua panel composition, dramatic cinematic light, webtoon-friendly vertical framing, no live-action, no Pixar-style CG, no 2D flat illustration, no watermark, no baked-in text` |
| 皮克斯 Disney 流 | `pixar-disney` | `3D rendered Pixar/Disney-style, rounded soft shapes, large expressive eyes, soft cinematic lighting, stylized non-photoreal materials, manhua panel composition with dynamic angles, no live-action, no 2D flat illustration, no watermark, no baked-in text` |
| 半厚涂 3D 写实流 | `semi-painterly-3d` | `3D rendered with painterly thick-coating, semi-realistic proportions, PBR materials with brushstroke texture, dramatic cinematic light, manhua panel composition, webtoon-friendly framing, no live-action, no 2D flat illustration, no Pixar/Disney cartoon, no watermark, no baked-in text` |

**连续性块**（贴在风格块之后、镜头内容之前；同角色/场景各镜保持不变，只改 action / camera）：

```
[continuity anchors: protagonist wearing [exact wardrobe], hair in [exact style], face shape [exact description]; scene layout [exact layout description]; 3D material: skin soft PBR non-photoreal, fabric [type] with [drape behavior]; lighting direction [left/right/top/etc]; color palette [warm/cool/neutral]]
```

**3D 特有角度匹配规则（硬失败）**：`side`/`tracking` → `character_3view_side`；`back` → `character_3view_back`；`front`/`three_quarter` → `character_main_card`；`wide` → `scene_main_card`；`overhead` → `scene_aux_card`。

### 1.2 `2d_animation` —— 2D 动画半解说短剧

- `visual_style_lock = 2D-cel-webtoon`（默认子模式 `guoman-webtoon`）
- 资产：角色卡 ×1 / 场景卡 ×1 / 道具卡 ≤1（**不需要三视图与场景辅卡**）
- 单镜 4–10s
- 重置锚周期：主角 3 / 配角 5 / 场景 4
- **首帧锚点可选**（不是必需输入）；真正的硬要求 = 每镜把角色/场景/道具**绑定到资产清单**并锁定空间站位与视线
- 旁白语速默认 **1.15**（清晰快速、钩子前置）
- 最小语音间隔 **0.20s**
- **交付终点 = 旁白交接**：不做最终剪辑/装配/字幕烧录/BGM 混音/导出 QC

**风格块（逐字）**

| 子模式 | 键 | 风格块 |
|---|---|---|
| 国漫 webtoon 流（默认） | `guoman-webtoon` | `2D cel-shaded animation, Chinese-animation webtoon style, clean bold black outlines, flat color fills with cel highlights, no 3D, no photoreal, no live-action, no watermark, no baked-in text` |
| 日漫赛璐珞流 | `cel-anime` | `2D cel-shaded anime, Japanese TV-anime cel style, soft cinematic lighting, clean dark line art, anime proportions, flat fills with subtle gradients, expressive anime micro-expressions, no 3D, no photoreal, no live-action, no watermark, no baked-in text` |
| 轻彩漫 webtoon 流 | `light-color-webtoon` | `2D webtoon / manhua full-color style, flat color fills, minimal shading, panel-driven composition, bold line art, bright clean backgrounds, expressive reaction shots, no 3D, no photoreal, no live-action, no watermark, no baked-in text` |

**10 条项目硬锁（不可在后期放宽）**：① 风格锁 ② H3 全能参考模式 ③ 旁白整集锁定（voice_id/profile/语速/音高/情绪/停顿/音量/采样率/编码/响度） ④**对白只取视频原声，不生成/不替换/不重配 TTS** ⑤旁白与对白**零重叠**（≥0.20s 保护间隔） ⑥旁白首轮**同一批次/母轨** ⑦旁白与对白**保持独立音轨**（禁 ducking/静音/截断/交叉淡化掩盖重叠） ⑧仅保证旁白一致性，不承诺对白跨镜音色一致 ⑨每镜资产绑定 + ID/哈希 ⑩**旁白窗口必须在分镜阶段预留并锁定**（没有可行窗口的镜头不得生成）

### 1.3 `live_action` —— 半解说真人短剧

- 无风格锁字段；摄影级真实感（纪录片 / 剧情片 / cinéma vérité）
- 角色卡：**16:9 纯白背景**，**左侧脸部特写 + 右侧正/侧/背半身三视图**
- 场景卡：**16:9 纯白背景，绝对不含人物**（含剪影/倒影也不行）
- 单镜 = **5–15 整数秒**；台词不足 5s 时合并相邻节拍
- **强制**：1 视频片段 → 1 张三格时间分镜图（三格用**片段内**时间码，不得写整集累计时间）
- 交付：**成片 + 字幕（可选）+ 独立 Seed Audio 旁白音频**三个独立交付物；**不把旁白混回视频**

**提示词必须压向摄影真实感的用词**：电影剧照 / 连续性参考图 / 选角照语言；真实光线、自然皮肤质感、可见毛孔与细发丝、可信衣料褶皱、正确镜头透视、克制色彩；纪录片感 / 剧情片感 / cinéma vérité；景深真实、运动模糊自然、面部运动可信。

**禁止项**：过度磨皮、塑料皮肤、轮廓过锐、二次元特征、CG 渲染感、插画感、过度美颜、夸张 AI 对称脸。

**H3 视频提示词固定装配顺序（10 条）**：① 镜头目的与精确时间段 ② 锁定身份来源（角色卡/场景卡/当前镜干净单格图及用途） ③ 真人写实目标 ④ 旁白对应画面 + 对白对应画面 ⑤ 主体站位（谁在/谁不在/各自站哪） ⑥ 动作节拍与情绪 ⑦ 构图与运镜（含段内切镜/推进/移焦/遮挡 reveal） ⑧ 对白、旁白与精确口型归属 ⑨ 连续性约束 ⑩ 负向约束。

**三格分镜提示词固定结构（8 条）**：① 片段编号/整数总时长/画幅/三个片段内时间点 ② 每张参考图职责 ③ 纸面排版与画面框尺寸（每格真正的横屏 16:9） ④ 第一格：空间建立与起始站位 ⑤ 第二格：明显不同的道具特写/情绪近景/机位变化 ⑥ 第三格：明显不同的关系景/过肩/反应/动作结果 ⑦ 连续性衔接 ⑧ 框外标签要求与负向约束。

> **禁止**把三格写成「同一远景的三个动作阶段」；**禁止**模型自行发明画面内文字。

### 1.3.1 真人写实轨 · 三格分镜图硬约束（★ 2026-10-21 实跑修订，P0）

> 来源：2026-10-20 / 10-21 两轮端到端实跑（EP01–EP05 共 40 余张分镜图，含三版 A/B/C 对照实验）。
> **本节覆盖上文与本文件冲突的旧写法**（旧写法内部有几何矛盾，见 ②）。

**① 分镜图不承担身份 —— 必须画灰阶三色调剪影**

真人质感的分镜图会携带可被人脸识别的身份信息；当它作为 H3 的参考图/首帧进入生成时，
会与角色卡争夺「身份来源」，等于主动引入第二个身份锚。实测四种替代（同镜同种子）：

| 方案 | 身份信息 | 传递能力 | 判断 |
|---|---|---|---|
| 铅笔粗稿 | **强**（五官可辨） | 影调最好 | **淘汰** |
| 矢量线稿 | 弱 | 空间丢失严重，易画成"人形面具" | 不推荐 |
| **灰阶块面（3 色调）** | **零** | 景别 + 光位 + 构图全保留 | **主方案** |
| 俯视站位图 | 零 | 唯一能表达"谁在哪 / 机位在哪 / 视锥范围" | **调度补充** |

规则：真人写实轨的三格分镜**必须**用 `flat grayscale value-block`（纯剪影、无面部细节）；
**禁止**照片质感或带五官的铅笔画。≥3 人同场、有走位、需明确机位的镜头**额外**产出一张站位图。

**② 画幅：竖版纸 9:16 + 三格横屏上下叠（"三格并排 + 每格 16:9"在几何上不可能）**

在一张 16:9 纸上并排放三个 16:9 横格，格子必然被压成竖格（A/B/C 三版实测全部出成竖格）。
纸面 16:9 → 每格只能 ≈5:9；要每格真 16:9 三格并排，纸需 ≈48:9。**二选一，推荐前者**：
竖版 9:16 纸、三格横屏 16:9 上下叠（便于手机审阅，也符合竖屏剧直觉）。

**③ 时间码逐格指认，否则三格印同一串**

写 `three time codes T0.0s / T2.0s / T5.0s` → 模型把三个码全印在**每一格**下方（A/B/C 全中）。
必须逐格指派（实测 E/F 两版一次正确）：

```
the top frame is captioned T0.0s, the middle frame is captioned T2.2s,
the bottom frame is captioned T5.0s. Only one caption per frame, nothing repeated.
```

**④ 可直接抄的模板**

```
SHEET FORMAT: one PORTRAIT 9:16 sheet of white paper. Three LANDSCAPE 16:9 frames stacked vertically,
separated by thin black gutters. Each frame has its own caption BELOW that frame only:
top = T0.0s, middle = T2.2s, bottom = T5.0s. Only one caption per frame, nothing repeated.

MEDIUM: flat grayscale value-block storyboard, exactly three tones — pure white, mid grey, dark charcoal —
no gradients, no texture, no colour. Every human figure is ONE FLAT SOLID SINGLE-VALUE SHAPE: a uniform fill
with NO internal shading, NO internal gradient, NO internal lines of any kind — no eyes, no nose, no mouth,
no chin or jaw line, no eyebrow, no cheekbone, no hair strands and no bun texture. The figure reads only as
an outer contour, like a cut-out paper shape pasted on the background.
STYLE: animation blocking value sketch, flat and graphic, hard edges, no rendering, no photorealism, no faces.
VALUE RULE: in every frame the human shape is the darkest thing on the page, filled solid charcoal from edge
to edge; the room around it stays pale grey and mid grey; there are no white or light-toned figures anywhere.
```

**⑤ 正文禁用词表（比 MEDIUM 段更硬的约束）**

只要面板正文出现 `chin / jaw / gaze / mouth / lip / eyebrow / cheekbone / nostril / face`
以及**职业词** `lawyer / judge / doctor / teacher`，模型就把"人"的先验压过"剪影"的先验：

- 实测 EP03 首轮 8 张里 **7 张带出五官轮廓**，尽管 MEDIUM 段写着 `no eyes, no mouth, no facial detail`；
- 实测 EP05 首版写出完整的脸与衣褶，触发点是 `the young lawyer in the linen blazer leans in over the desk`
  （EP04 成功版是 `a single figure behind the glass`）。

改法：主体一律用**体块代称**（`the shorter, rounder figure` / `the broad, tall male figure` /
`the figure in a long open robe`），情绪一律换成体态（肩线、颈部、手的角度、重心）或光位。
`her chin slightly down, her gaze angled down-left` → `the whole head a single flat dark oval with only
a slight downward tilt to read the pose, nothing inside it`。

**⑥ 剪影的代价，必须显式承认**

剪影**不能表达五官微表情**。剧本阶段就应避免「眼部特写 / 眼神一变」这类依赖微表情推进的镜头设计，
否则到分镜阶段会被迫改写。有效替代：
`大特写·眼睛抬起` → `头肩剪影近景，下巴抬起几度，左轮廓一道细白轮廓光`；
`镜片反光挡住眼睛` → `黑头部剪影上一个黑圈（镜框），圈内一块纯白覆盖整个眼区`；
`表情复杂` → 不表达，交给 H3 提示词的情绪节拍。

**⑦ 顺带解决「纸上出现可读文字」**

真人质感下纸是白的，模型天然想往上写字，`no readable text` 压不住（cfg=1 时负向词本就无效）。
灰阶块面里纸就是一块纯白矩形 —— **实测 0 处可读文字**。靠画风结构性地消除文字，比靠提示词禁止可靠。

**⑧ 站位图（blocking diagram）写法 + 三个实测坑**

```
A top-down floor-plan blocking diagram for one shot, horizontal 16:9 white sheet, black uniform-weight
line art, no colour, no shading, no texture, no realistic figures.
Human positions = ROUND black dots with a small arrow for facing direction (never triangles or squares).
Camera = one filled black triangle with a dashed wedge-shaped field of view, marked CAM A.
EVERY seat in the public spectator seating is EMPTY — no circles, no dots, no arrows — with the single
exception explicitly named below.
Title at the top reads BLOCKING - EP01 SC04 in small monospace lettering.
Legend: witness box = grandma   counsel table = father + lawyer   platform = judge
```

| 坑 | 现象 | 解法 |
|---|---|---|
| `bench` 有歧义 | `circle marked J in the bench` → J 被放进**旁听长椅** | 一律写 `the JUDGE'S RAISED PLATFORM — an elevated desk on a dais`，并显式 `NOT in the spectator rows` |
| 单字母标注被错配 | `J / A / S / O` 两次实测被互换 | **图上不写字母**：只画裸圆点，身份靠位置 + 标题下图例自解释 |
| 旁听席被自动填满 | 每排座位都画上小圆点，看起来坐满了 | 必须写 `EVERY seat … EMPTY — no circles, no dots, no arrows` |

关键语义标记要**加重**：SC-07 的核心是「指向一把空椅」，首版漏了虚线环（该镜分镜图等于失效）。
写法升级为 `THE KEY MARKER, most important element on the sheet: a LARGE CLEAR DASHED RING, diameter
about four times the filled dots, inside completely white and empty` —— 加重后一次到位。

**⑨ 分镜图进 H3 的写法：`weak_reference`，禁止 `fully_preserved`**

`ref-en.txt` §2.2 本来就有一类「storyboard reference」（"defining their viewpoint, subject placement,
and shot order"），所以这条路是**官方一等公民**，不需要发明写法：

- `subject_definitions` 写 `It is a planning diagram only … and it is NOT a keyframe.`
- `retention_analysis` 给 `<Picture N>: weak_reference - only the camera distance, subject placement,
  light direction and shot order … are followed`（**禁止**写 `fully_preserved`，那会让模型复刻剪影质感）

**⑩ 引用义务下调**：分镜图既不承担身份，`storyboard.json` 里为它登记的 `character_refs / scene_refs`
降级为**调度信息**（谁在画面里、在哪个场地），不再作为出图参考图传入。

**⑪ 纯手部特写要显式写「画面里只有手」**

`办公室 + 有人在办事` 的常识会让模型补一个对话者（实测两人的手出现在三格里）。
开头加 `ONLY HANDS AND OBJECTS ARE IN THESE THREE FRAMES — no head, no face, no body, no second person
anywhere.`，并在每格重复 `the same hands`。

## 二、`storyboard.json` 契约（三类校验的输入）

落点：`<05-分镜>/storyboard.json`

```json
{
  "ep": "ep01",
  "style": "3d_manhua",
  "shots": [
    {
      "shot_id": "01",
      "duration": 8.0,
      "is_action": false,
      "is_emotion": false,
      "is_monologue": false,
      "shot_camera_angle": "three_quarter",
      "first_frame_anchor_role": "character_main_card",
      "first_frame_angle_match": { "anchor_view": "front_3/4", "angle_match_confirmed": true },
      "reset_anchor": true,
      "narration_lines": [ { "text": "那一刻，我终于看清了门口的人。", "start": 0.0, "end": 3.6 } ],
      "dialogue_lines":  [ { "speaker": "萧珩", "line": "你该行礼了。", "tone": "冷淡", "start": 4.1, "end": 6.0 } ],
      "plot_point_refs": ["P001"]
    }
  ],
  "assets": {
    "characters": [ { "name": "林夏", "main_card": "assets/characters/林夏_main.png",
                      "three_view": "assets/characters/林夏_3view.png" } ],
    "scenes":     [ { "name": "客厅", "main_card": "assets/scenes/客厅_main.png",
                      "aux_card": "assets/scenes/客厅_aux.png" } ],
    "props":      [ { "name": "手机", "card": "assets/props/手机_card.png" } ]
  }
}
```

- 无旁白填 `[]`；`narration_lines[].start/end` 为**相对本镜起点**的秒数。
- `is_action` 切换到动作/快切时长口径；`is_emotion` / `is_monologue` 切换到对应旁白字数上限。
- `three_view` / `aux_card` 只在画风要求时必填（3D 必须，2D/真人不需要）。

## 三、校验口径（`half_narrated_check.py`）

| 子命令 | 校验内容 |
|---|---|
| `windows` | 单镜时长区间、旁白字数上限、旁白/对白**零重叠**且间隔 ≥ `gap_min_s`、旁白/对白占比上限、**尾缓冲**、语音区间不越镜、**跨镜最小间隔** |

## 五、平台专有项（本仓库无法复刻，需用户在平台侧完成）

以下能力属于 MiniMax Design 平台专有，本仓库只能在**规格与校验层**对齐，**不能代跑**：
