# Prompt Skills、导演 Skill 与 TTS 模型

## 提示词增强

- 图片生成节点和视频生成节点均提供“提示词优化”。
- `通用增强`：根据当前媒体类型、画幅、时长、参考素材和项目画风生成生产级提示词。
- `H3 增强`：先执行通用增强，再读取内置 H3 Prompt Skill 执行第二次结构化改写。
- 如果项目或节点选择了导演 Skill，Skill 正文会作为创意约束参与增强。
- 增强只修改提示词，不会自动发起图片、视频或音频生成，也不产生媒体费用。

## 图片提示词设定

- `角色四视图`：脸部特写、正面全身、侧面全身、背面全身。
- `角色设定卡`：肖像、三视图、表情、动作、道具和配色设定板。
- 两种预设都会继承当前节点画风，可继续使用通用或 H3Image 增强。

## Skills 模块

- 设置 → Skills 可导入、查看、启用、禁用、编辑和导出 Skill。
- 支持 `.zip`、`.md`、`.tar`、`.tar.gz`、`.tgz`。
- 建项或工作台“项目规格”中可以指定项目级导演 Skill。

## TTS 媒体模型

媒体模型 → 添加供应商 → `SoloDrama TTS`。

支持两种协议：

- OpenAI TTS 兼容：`POST {baseUrl}/v1/audio/speech`
- IndexTTS 2.5：额外发送语言、情绪、表演说明和 `generation.duration_factor`

本地默认地址：`http://127.0.0.1:8000`

音频生成节点会自动显示音色 ID、语速、情绪、表演说明、IndexTTS 时长系数和采样温度。本地地址成本显示为 0；第三方接口未返回可核验价格时保持“未知”，不回退为 0。

旧内置 `localTts` 工具不再默认安装；用户自行改写或自定义 author 的同名工具不会被自动删除。TTS 生成的逐镜音频可以直接作为剪映草稿或流水线出片的逐镜音轨；已有 `solodrama-voice-rough-cut` 清单仍可继续兼容读取。
