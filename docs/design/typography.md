# 排版系统 · SoloDrama 2.0

## 1. 字体策略：本地优先，不引外链

**决策**：不引入 Google Fonts / 任何 CDN 字体。

理由：

1. 产品定位是**本地优先**，断网必须能用（预检、出片、剪辑全在本地）。
2. 外链字体在弱网下会 FOUT，正文闪一下再换字形，专业观感直接崩。
3. 仓库零构建，没有字体子集化流程；直接塞 3–5MB 中文字体进 git 会让 `manifest.sha256` 与 clone 体积不可接受。

**做法**：字体栈优先本机已装字体，逐级回退到系统字体。用户在系统里装 Noto Sans SC 就自动用上，不装也不影响观感一致性（回退到苹方/微软雅黑，同属黑体）。

## 2. 字体栈

```css
/* UI / 正文：中文黑体优先，西文无衬线优先 */
--sd-font-ui:
  "Inter", "Manrope", "Geist Sans",
  "PingFang SC", "HarmonyOS Sans SC", "Noto Sans SC", "Source Han Sans SC",
  "Microsoft YaHei", -apple-system, "Segoe UI", system-ui, sans-serif;

/* 展示标题：中文衬线优先（片名感），西文衬线回退 */
--sd-font-display:
  "Playfair Display", "Noto Serif SC", "Source Han Serif SC", "Songti SC",
  "SimSun", Georgia, "Times New Roman", serif;

/* 等宽：数字表、镜号、时间码、提示词、日志 */
--sd-font-mono:
  "JetBrains Mono", "Cascadia Mono", "SF Mono", "Consolas", "Menlo",
  ui-monospace, monospace;
```

**为什么展示标题用衬线**：短剧是「剧」，片名与集号是作品的一部分。衬线在深底上有银幕片头的气质；全站唯一使用衬线的地方就是剧名与页头主标题，其余一律黑体。

**为什么镜号/时间码必须等宽**：`shot_007`、`00:12.480`、`¥12.40` 在列表里纵向排列时，比例字体会让小数点与数字宽度不齐，逐行扫读会跳。这是专业工具与玩具的分界线之一。

## 3. 字阶

| Token | 尺寸 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `--sd-fs-display` | 34 / 1.20 | 600 | 剧名、首页主标题（配衬线） |
| `--sd-fs-h1` | 24 / 1.30 | 600 | 页头标题 |
| `--sd-fs-h2` | 19 / 1.35 | 600 | 区块标题、卡片组标题 |
| `--sd-fs-h3` | 16 / 1.40 | 600 | 卡片标题、抽屉标题 |
| `--sd-fs-body` | 15 / 1.55 | 400 | 正文基准（2026-10-29 上调后定为 15px） |
| `--sd-fs-sm` | 13 / 1.50 | 400 | 次要说明、表格副行 |
| `--sd-fs-caption` | 12 / 1.45 | 400 | 元信息、表头、时间戳 |
| `--sd-fs-label` | 11 / 1.40 | 600 | 分组标签（字间距 +0.06em，全大写感） |
| `--sd-fs-mono` | 13 / 1.50 | 400 | 等宽场景 |

**为什么正文 15px 不是 14px**：项目历史上做过一次「整体上调一档」，用户原话是「字小、看着累」。15px 在 1080p 与 2K 上都稳。**不要因为「看起来更精致」改回 14px**，那是拿可读性换观感。

## 4. 中文排版细则

| 规则 | 值 | 说明 |
|---|---|---|
| 正文行高 | 1.55 | 中文方块字需要比西文更大行距 |
| 标题行高 | 1.2–1.4 | 越大的字行距越紧 |
| 中英混排间距 | 不手动加空格 | 交给字体与 `font-feature-settings`，手加空格会在不同字体下错位 |
| 段落间距 | 0.75em | 不用空行堆 |
| 首行缩进 | **不用** | 界面文本不缩进，那是书籍排版 |
| 字间距 | 正文 0，标签 +0.06em | 标签靠字间距建立「分组感」 |
| 数字 | 等宽 + `font-variant-numeric: tabular-nums` | 表格数字必须对齐 |

## 5. 层级约束（防滥用）

1. **一屏最多 3 个字号**（标题 / 正文 / 元信息）。出现第 4 个就开始像海报不像工具。
2. **字重只用 3 档**：400 / 500 / 600。不用 700（中文粗体在 Windows 上会糊）与 300（深底细体发虚）。
3. **不使用下划线表示强调**（那是链接），用字重或强调色。
4. 全大写只用于英文标签（如 `STATUS`），中文不用全大写概念。

## 6. 落地方式

`web/ui/studio/css/tokens.css` 中 `--sd-font-*` / `--sd-fs-*` 为真源。
旧变量 `--font-ui` / `--font-mono` / `--fs-11…--fs-26` 保留为**别名**，指向新 Token，保证 22 个视图零改动继续工作。

```css
/* 旧名 → 新名映射（不要删旧名，22 个视图在用） */
--font-ui: var(--sd-font-ui);
--fs-13: var(--sd-fs-body);   /* 旧名里的 13 实际是 15px，见 03 审计 §4.2 */
```

## 7. 验收

- 中文标题在深/浅两套下都不出现「字重不足发虚」。
- 表格里 `¥12.40` / `¥9.80` 小数点纵向对齐。
- 把系统字体临时换成「微软雅黑」后，版面不塌（行高与宽度变化可接受，不能溢出）。
