# 组件规范 · SoloDrama 2.0

> 只定义**规则与状态**，不写完整 CSS（CSS 在 `web/ui/studio/css/`，Token 在 `tokens.css`）。
> 「现有类名」一列是真实在用的，2.0 **不得随意改名**（22 个视图在用）。

## 1. 按钮

| 变体 | 类名 | 用途 | 一屏上限 |
|---|---|---|---|
| 主操作 | `.btn.primary` | 当前视图**唯一**推荐动作 | **1** |
| 次操作 | `.btn` | 常规动作 | 3 |
| 静默 | `.btn.quiet` | 取消、关闭、辅助 | 不限 |
| 幽灵图标 | `.btn.ghost.icon` | 顶栏工具（刷新、关闭） | 不限 |
| 危险 | `.btn.danger`（2.0 新增） | 删除、覆盖、清空 | 1，且必须二次确认 |

规则：

1. **主按钮只有一个。** 出现两个，用户就要读文字才能决定，等于没有推荐。
2. 计费动作的主按钮**必须带价格**：`生成 12 镜 · 约 ¥2.40`，不许只写「生成」。
3. 加载中：按钮内换成 `<span class="spinner"></span>` + 保留原文案宽度（防跳动），禁用点击。
4. 危险动作按钮**不用金色**，用 `--sd-danger` 描边 + 文字，避免与"花钱"语义混淆。

## 2. 输入

| 元素 | 类名 | 规则 |
|---|---|---|
| 文本框 | `.input` | 底用 `--sd-inset`；聚焦时边框变 `--sd-accent` + 1px 内阴影，**不发光** |
| 搜索 | `.search`（含内嵌图标） | 图标在左，占位文案写"搜什么"不写"搜索" |
| 下拉 | `select.input` | 原生控件 + `color-scheme` 跟随主题，不造自定义列表（无障碍成本高） |
| 多行 | `textarea.input` | 等宽可选；提示词编辑区必须等宽 |
| 复选框 | `.check` | 命中区 ≥ 32×32，视觉 16×16 |

校验规则：**错误文案在字段下方，不在顶部弹 toast**。toast 会消失，字段旁的错误不会。

## 3. 状态标记

| 标记 | 类名 | 说明 |
|---|---|---|
| 圆点 | `.dot.done/.doing/.todo` | 6px 实心；`doing` 才有呼吸动画 |
| 徽标 | `.badge` `.badge.warn` `.badge.outline` | 文本型，字号 `--sd-fs-label` |
| 告警块 | `.alert.info/.warn/.bad` | 一行图标 + 一段话，**必须给下一步** |

规则：颜色永远不是唯一信号。`dot` 旁边必须有文字（"通过"/"阻塞"），色盲用户可读。

## 4. 卡片

| 类型 | 结构 | 规则 |
|---|---|---|
| 面板卡 | `.card` > `.card-b` | 圆角 `--sd-radius-lg`，1px 描边，无投影 |
| 项目海报卡（2.0 新增 `.sd-poster`） | 图 2:3 + 底部渐变 + 标题 + 阶段条 | 图缺失时用场记板线条图 + 首字 |
| 统计卡 | 标题 + 大数字 + 单位 + 来源标注 | 数字等宽；**必须标来源**（"实付"/"估算"） |

卡片纪律：

- 不给卡片加投影（深色下投影等于脏；浅色下靠描边分层）。
- 卡片不是容器套娃：**最多两层**（面板 > 卡片），出现第三层改用分隔线。

## 5. 表格

- 表头：`--sd-fs-caption` + `--sd-text-3` + 底边 `--sd-line-strong`。
- 行高 `--sd-row-h`（44px），斑马纹**不用**（用悬停高亮）。
- 数字列右对齐 + `tabular-nums`；镜号/时间码左对齐 + 等宽。
- 空表格不显示表头骨架，直接给空状态。

## 6. 浮层

| 类型 | 用途 | 规则 |
|---|---|---|
| 抽屉 `.drawer` | 详情、编辑、项目切换 | 右侧滑入，宽 420px（窄屏全宽） |
| 模态 `.modal` | **确认 / 危险操作** | 仅此两类；不做"表单模态" |
| Toast `.toasts` | 结果反馈（成功/失败一句话） | 3.2s 自动消失；失败不自动消失，需手动关 |
| 遮罩 `.scrim` | 共用 | 点击关闭抽屉/模态；Esc 同效 |

## 7. 生产中新增的三个组件（Phase 2–4 落地）

### 7.1 阶段条 `.sd-stages`

13 节点的可视化。**不是进度条**，是状态矩阵。

```
[导入●] [资产●] [分镜图●] [出片●] [剪辑●]
   ●passed  ○absent  ◐doing  ◑blocked  ✕failed
```

规则：

- 每个节点显示 **名称 + 状态 + 一句为什么**（读 `nodes.py` 的 `why` 字段，不另写文案）。
- `blocked` 必须显示「上游未通过：X」，这是用户最需要的一句话。
- 点击节点进入该节点的产物页，**不做原地执行**（执行入口统一在控制中心，防误点计费）。

### 7.2 六段式提示词编辑器 `.sd-prompt-sec`

```
subject_definitions   ← 主体定义（谁在图里）
summary               ← 任务类型 [reference generation]
retention_analysis    ← 保留/迁移分析
detailed_description  ← 动作与镜头（最长）
overall_soundscape    ← 环境声
non_diegetic_music    ← 非画内音乐
```

规则：

- 六段**固定顺序**，不可拖拽排序（顺序即契约，见 `h3_prompt.py:55`）。
- 每段独立可折叠，显示字数与 `CJK` 占比。
- 段头右侧显示该段的**规则命中**（`SHOT018/019/020/021`），点击展开原因。
- 「台词标记」检查：`<d>[Chinese] …</d>` 缺失时**就地红框**，不弹窗。
- 保存按钮旁显示「与文件差异：+12 / -3 行」，保存前给 diff。

### 7.3 成本行 `.sd-cost-row`

```
云端出片   12 镜 × ¥0.20      ¥2.40   实付 · 2026-11-10 14:22
```

规则：**实付与估算分两行**，永不合并成一个数；无台账时显示「本次未产生计费调用」，不显示 ¥0.00。

## 8. 空 / 错 / 载 三态（统一实现，不许各页自造）

| 态 | 内容 | 组件 |
|---|---|---|
| 空 | 为什么空 + 下一步 + 按钮 | `.empty` > `.empty-t` + `.empty-h` |
| 错 | 错误一句话 + 可操作建议 + 重试按钮 | `ui.js::errorCard` |
| 载 | 骨架 3 行 | `ui.js::skeleton` |

**禁止**：「暂无数据」「出错了」「加载中…」这类无信息量的文案。

## 9. 图标

- 内联 SVG 精灵，`<span data-ico="name">`，由 `ui.js::paintIcons` 填充。
- 尺寸只有两档：16（正文/按钮内）、20（顶栏）。**不出现 24/32 图标**（大图标在密集界面里只会占地方）。
- 描边 1.5px，`currentColor`，不填色（除状态点）。

## 10. 键盘与可达性

| 要求 | 现状 | 2.0 目标 |
|---|---|---|
| 焦点可见 | 3 处 `:focus-visible` | 全部可交互元素统一 `outline: 2px solid var(--sd-accent); outline-offset: 2px` |
| Esc 关闭浮层 | 已实现 | 保留 |
| Tab 顺序 | 天然 DOM 顺序 | 抽屉/模态打开时**焦点锁定**（2.0 补） |
| 屏幕阅读器 | 导航/浮层/toast 有 ARIA | 补 `aria-current`、表单 `aria-describedby` |
