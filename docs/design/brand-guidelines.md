# 品牌视觉指南 · SoloDrama 2.0

> 定位一句话：**Cinematic AI Production Studio —— 午夜电影工作室里的 AI 短剧片场。**
> 本文是**唯一品牌口径**。`docs/design/design-tokens.md` 是它的代码化实现，冲突时以本文为准、以 Token 落地。

## 1. 我们是什么，不是什么

| 是 | 不是 |
|---|---|
| 一间工作室：有片场、有胶片、有台账 | 一个 SaaS 后台（表格 + 侧边栏 + 蓝色主按钮） |
| 专业影视制作工具（像剪辑软件一样可信） | 创意玩具（大圆角、彩虹渐变、满屏动效） |
| 本地优先：数据在用户硬盘上 | 云工作台：上传、同步、订阅 |
| AI 是执行者，人做决定 | AI 是黑箱，按钮一点就花钱 |

**拒绝清单**（写进评审检查项）：

- 拒绝普通 SaaS 后台风格：白卡片 + 阴影 + 品牌蓝主按钮 + 圆角 12px 的通用后台。
- 拒绝照搬参考项目 `cwp-cwp/ai-video` 的页面结构、配色、字体、布局、组件。**只学功能组织，不学视觉。**
- 拒绝「为了好看而藏功能」：专业功能（参数、门禁、日志、退出码）必须可找到。
- 拒绝「为了全展示而拥挤」：同屏不超过一个主张（一个标题、一个主按钮、一个结论）。

## 2. 视觉母题

**午夜 · 胶片 · 场记板。**

- **午夜**：底色不是纯黑，是带蓝调的墨（Midnight Ink）。纯黑会让画面「死」，带蓝才有空间感。
- **胶片**：象牙色文字（Soft Ivory）而不是纯白。纯白在深底上会「发跳」，象牙像打在银幕上的光。
- **场记板**：强调色只有一支香槟金（Cinematic Amber），像片场的灯光；蓝绿（Muted Teal）只做「数据/实时」的辅助信号。

三条硬规则：

1. **强调色不做装饰。** 香槟金只出现在：品牌标记、主操作、当前选中、需要人注意的代价（计费/风险）。
2. **一屏一个主张。** 主标题 + 主按钮 + 主数字，各一个。两个「最重要」等于没有重点。
3. **数字要能被核对。** 所有数字带单位与来源（`¥12.40 · 实付` / `3/13 节点`），不出现无源数字。

## 3. 双主题的分工（不是"深色版/浅色版"）

| 主题 | 用途 | 情绪 |
|---|---|---|
| **深色（默认）· Midnight Studio** | 看片、分镜、剪辑、长时间盯画面 | 暗房：画面是唯一亮的东西，UI 退到背景 |
| **浅色 · Warm Paper** | 写剧本、读文档、填表单、白天办公 | 案头：纸与墨，长时间阅读不刺眼 |

结论：**主题切换不是偏好设置，是工作模式切换。**因此两套主题都要完整（不能「浅色是深色的降级版」），且切换必须瞬时、无闪白、记忆上次选择。

## 4. 语气与文案

| 场景 | 写法 | 反例 |
|---|---|---|
| 状态 | 「12/13 节点通过」 | 「运行正常」 |
| 失败 | 「缺 3 张分镜图：shot_007 / 012 / 018」 | 「生成失败，请重试」 |
| 计费 | 「本次预计 ¥2.40（云端 12 镜 × ¥0.20）」 | 「将消耗额度」 |
| 空状态 | 「还没有分镜图。先导入制作包，再跑分镜图。」 | 「暂无数据」 |
| 已移除能力 | 「本版本不提供自动封面生成」 | 保留按钮但不响应 |

文案纪律：

- **不承诺做不到的事**：不写「AI 保证不出错」，写「预检会拦下 3 类结构错」。
- **门禁失败不是错误**：`rc=2` 显示「缺 N 项」并列出，不显示「接口异常」。
- **不编造数值**：没有台账就不显示金额，只显示「本次未产生计费调用」。

## 6. 版面骨架

```
┌───────────┬──────────────────────────────────────────┐
│ 侧栏 252  │ 顶栏 60：项目切换 · 健康 · 资源 · 主题   │
│ 品牌      ├──────────────────────────────────────────┤
│ 五个工作  │ 内容区（max 1440，居中，左右留 32）      │
│ 空间      │  · 页头：标题 + 一句说明 + 主操作        │
│ 项目入口  │  · 主体：卡片 / 表格 / 画布              │
│ 系统设置  │  · 底部：无（不要再加一条工具栏）        │
└───────────┴──────────────────────────────────────────┘
```

- 侧栏宽度固定 252px（折叠 64px），**不做可拖拽**：拖拽宽度是最容易做出半像素错位的交互，收益远小于维护成本。
- 内容区最大宽度 1440px。超宽屏（>1500px）不拉伸卡片，改为增加列数。
- 浮层只有两种：右侧抽屉（详情/编辑）+ 居中模态（确认/危险操作）。**不再新增第三种。**

## 7. 图像与空状态

- 项目卡用**海报比例 2:3**，图片 `object-fit: cover`，下方压 60% 黑色渐变保证标题可读。
- 无图时不用灰色占位方块，用「片场场记板」线条图 + 项目名首字。
- 空状态必须回答三件事：**为什么是空的**、**下一步做什么**、**去哪做**（给按钮）。

## 8. 评审问题清单（每次交付自问）

1. 遮住 Logo，还认得出这是 SoloDrama 吗？
2. 这一屏最重要的一个东西是什么？它是不是最显眼的？
3. 有没有哪个数字是我编的？
4. 有没有哪个按钮点了没反应？
5. 深色和浅色，各自单独看是否成立（不是"也能看"）？
6. 中文排版有没有出现「标题字重不够 / 数字与中文混排不齐」？
