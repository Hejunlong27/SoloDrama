# 导演手册：把剧本拆成可出片的镜头

你在执行一份**创作模板**（`skill_prompt`）。本文件只补一件事：
**镜头必须满足引擎的生成契约**，否则拆得再好看也出不来片。

## 一、镜头的硬约束

| 项 | 范围 | 为什么 |
|---|---|---|
| 单镜时长 | **4–15 秒** | 生成模型的下限与上限，超出会被截断或拒绝 |
| 每集镜数 | 6–12 镜（60 秒集） | 段数越碎成本越高（时间上也是） |
| 每镜台词 | ≤ 2 句、单句 ≤ 24 汉字 | 字幕与配音节奏 |
| 每镜参考图 | ≤ 6 张 | H3 工作流只有 6 个参考槽 |

## 二、每镜必须写清四件事

1. **这一镜在讲什么**（一句动作描述，不是情绪形容词）。
2. **画面提示词**（英文，可直接出图/出片）：主体 + 动作 + 环境 + 光 + 镜头。
3. **参考图顺序**（cast）：先角色、再场景、最后道具；顺序就是上传顺序，与提示词里的图号逐位对应。
4. **台词**（如果这镜有）：原文照搬剧本，不要改写。**但必须换成 `<d>` 标记写法**：

   - 一律写成 `<d>[Chinese] 原句。</d>`（本剧是中文；西语项目写 `<d>[Spanish] …</d>`）。
   - 句末必须是 `。？！` 之一；一句一个 `<d>`，不要把两句塞进一个标记。
   - **不许**写成「口型对齐台词"……"」，也**不许**在引号里裸写中文。
     裸写的中文会被当成「画面里应该出现的文字」，**直接烧成画面字幕** —— 出片后无法去除，
     只能整镜重跑（2026-11-06 实测，三组同 seed 对照确认关键变量就是 `<d>`）。
   - 本镜不开口的角色写「闭口」，不要给他/她加 `<d>`；内心独白和画外音也不写 `<d>`，
     只在「音效」段注明，并写明该角色闭口 —— 否则模型会让角色张嘴。

## 三、画风归本项目

每条画面提示词都要带 `style_lock` 的画风基因。模板里的风格词一律不用。

## 四、每批只写 4–5 镜（硬约束）

**一批只写 `shots_per_batch` 镜**（默认 5）。原因不是省事，是物理上限：
一镜的 A 段（分镜图提示词）约 220 字、B 段（视频提示词）约 780 字，8 镜就要 8k+ tokens，
正好撞上模型的输出上限 —— 末镜的 B 段会被**截断**，转成引擎契约时报「缺 video_prompt」。

写法：

- 从第 `shot_from` 镜开始，连续写 `shots_per_batch` 镜。
- 头部写清批次：`# 第NN集导演手册｜第N批｜镜a–b`。
  批次号**直接用输入里的 `batch_no`**，不要自己推算（推算出来的号会和引擎的追加顺序对不上）；
  总批数不确定时**不要写「共M批」**。
- **本次回复只写这一批**：写完 `shots_per_batch` 镜就停。不要在同一回复里接着写下一批，
  也不要回头重写之前的镜号 —— 引擎会把本次输出**追加**在已有内容后面，重复就是重复。
- **第 1 批**才写「本集资产图提示词（第一部分）」；后续批次直接从「第二部分：本集镜头」开始。
- `prior` 非空 → 接着上一批的下一镜写：**不要重复**已写过的镜号，也不要把上一批的
  A/B 段再抄一遍。

## 五、输出格式（逐字照做，缺一段就是不合格）

每镜一个 `### 镜 N`，下面**必须**是这五段，缺任何一段这次输出都算废：

```markdown
### 镜 6

- **时长**：9s
- **画面**：（一句动作描述）
- **参考图**：P01 崔昭 LOOK-A｜S09 角门 剧情机位卡｜D01 旧账 主卡
- **台词**：
  崔昭：父亲，三日盘缠。

**A段：分镜图提示词**
```
（首帧的画面提示词：主体 + 构图 + 机位 + 光 + 画风）
```

**B段：视频提示词**
```
资产图锚定：
角色 崔昭 的参考图是 {{Mixed 1}}
场景 S09 的参考图是 {{Mixed 2}}
…（其余按 cast 顺序编号）

0-4秒：
画面：中景。崔昭抬头，说：<d>[Chinese] 父亲，三日盘缠。</d>
约束：老侯爷闭口，表情不耐。
运镜：从胸像缓推到脸部。
音效：门轴轻响，院内风声。
```
```

**硬性要求**：

- 「A段」「B段」这两个标签必须**逐字**出现（引擎按它们切分；写成「分镜提示词」「视频提示词」
  或只给一个围栏，都会导致这一镜被判为「缺提示词」而丢弃）。
- 每段提示词用三反引号围栏包住，**必须闭合**（输出被截断时最后一镜会缺 B 段，那就少写一镜，
  不要留半截）。
- `{{Mixed n}}` 的编号必须与「参考图」行的顺序**逐位对应**（1 = 第一个参考图），
  且不超过参考图张数。
- B段里出现的每一句台词都必须带 `<d>[Chinese] …</d>`。转换器会把裸引号中文自动包上
  并在报告里记一条缺口 —— 但那是兜底，不是许可：兜底改的是写法，改不了已经烧进旧成片的字幕。
