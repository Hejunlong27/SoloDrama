# 导演手册：把剧本拆成可出片的镜头

你在执行一份**创作模板**（`skill_prompt`）。本文件只补一件事：
**镜头必须满足引擎的生成契约**，否则拆得再好看也出不来片。

## 一、镜头的硬约束

| 项 | 范围 | 为什么 |
|---|---|---|
| 单镜时长 | **4–15 秒** | 生成模型的下限与上限，超出会被截断或拒绝 |
| 每集镜数 | 6–12 镜（60 秒集） | 段数越碎成本越高（时间上也是） |
| 每镜台词 | ≤ 2 句、单句 ≤ 24 汉字 | 字幕与配音节奏 |
| 每镜参考图 | ≤ 6 张 | H3 工作流只有 6 个参考槽 |

## 二、每镜必须写清五件事

1. **这一镜在讲什么**（一句动作描述，不是情绪形容词）。
2. **A 段：首帧画面提示词**（英文，给生图模型）：主体 + 构图 + 机位 + 光 + 画风。
3. **B 段：视频提示词**（H3 多参六段式，见 §五）：说清每张参考图是谁、每一秒发生什么。
4. **参考图顺序**（cast）：先角色、再场景、最后道具。这个顺序就是 `<Picture n>` 的编号 ——
   `1` 是分镜图，`2` 起依次对应。顺序一错，模型就会把场景当成人。
5. **台词**（如果这镜有）：原文照搬剧本，不要改写。**但必须写成 `<d>` 标记**：

   - 一律写成 `<d>[Chinese] 原句。</d>`（本剧是中文；西语项目写 `<d>[Spanish] …</d>`）。
   - 句末必须是 `。？！` 之一；一句一个 `<d>`，不要把两句塞进一个标记。
   - **不许**写成「口型对齐台词"……"」，也**不许**在引号里裸写中文。
     裸写的中文会被当成「画面里应该出现的文字」，**直接烧成画面字幕** —— 出片后无法去除，
     只能整镜重跑（2026-11-06 实测，三组同 seed 对照确认关键变量就是 `<d>`）。
   - 本镜不开口的角色写「闭口」，不要给他/她加 `<d>`；内心独白和画外音也不写 `<d>`，
     只在 `overall_soundscape` 里注明，并写明该角色闭口 —— 否则模型会让角色张嘴。

## 三、画风归本项目

每条画面提示词都要带 `style_lock` 的画风基因。模板里的风格词一律不用。
写进 B 段时，画风基因放在 `detailed_description` 的**第一句**，不要单独占一行方括号。

## 四、每批只写 4–5 镜（硬约束）

**一批只写 `shots_per_batch` 镜**（默认 5）。原因不是省事，是物理上限：
一镜的 A 段约 220 字、B 段（六段式）约 900 字，8 镜就要 9k+ tokens，
正好撞上模型的输出上限 —— 末镜的 B 段会被**截断**，转成引擎契约时报「缺 video_prompt」。

写法：

- 从第 `shot_from` 镜开始，连续写 `shots_per_batch` 镜。
- 头部写清批次：`# 第NN集导演手册｜第N批｜镜a–b`。
  批次号**直接用输入里的 `batch_no`**，不要自己推算（推算出来的号会和引擎的追加顺序对不上）；
  总批数不确定时**不要写「共M批」**。
- **本次回复只写这一批**：写完 `shots_per_batch` 镜就停。不要在同一回复里接着写下一批，
  也不要回头重写之前的镜号 —— 引擎会把本次输出**追加**在已有内容后面，重复就是重复。
- **第 1 批**才写「本集资产图提示词（第一部分）」；后续批次直接从「第二部分：本集镜头」开始。
- `prior` 非空 → 接着上一批的下一镜写：**不要重复**已写过的镜号，也不要把上一批的
  A/B 段再抄一遍。

## 五、输出格式（逐字照做，缺一段就是不合格）

每镜一个 `### 镜 N`，下面**必须**是这五段，缺任何一段这次输出都算废：

```markdown
### 镜 6

- **时长**：9s
- **参考图**：P01 崔昭 LOOK-A｜S09 角门
- **台词**：
  崔昭：父亲，三日盘缠。

**A段：分镜图提示词**
```
first frame, medium shot, young woman at a courtyard gate at dusk, grey-green robe,
hair tied with a wooden pin, backlit rim light, 2D cel webtoon
```

**B段：视频提示词**
```
subject_definitions:
<Picture 1> 是本镜分镜图（首帧构图锚点）：黄昏角门前的全景，崔昭立于门内侧。
<Subject 1> 是 <Picture 2> 中的崔昭：二十四岁，灰青窄袖交领长衫，发髻一支木簪，左腕一道浅疤。
<Subject 2> 是 <Picture 3> 中的角门：斑驳朱漆、半掩门扇、门外一条青石甬道。

summary:
[reference generation] 目标视频呈现 <Subject 1> 在 <Subject 2> 前停步、抬手叩门的两拍动作，参考图提供其形象与该门的结构。

retention_analysis:
<Subject 1>（出现于 [Shot 1]、[Shot 2]）：fully_preserved - 保留其灰青长衫、木簪与左腕浅疤。
<Subject 2>（出现于 [Shot 1]、[Shot 2]）：fully_preserved - 保留朱漆门扇、门环与青石甬道。
<Picture 1>（[Shot 1] 首帧）：partially_preserved - 保留机位与门内外的站位关系。

detailed_description:
2D-cel-webtoon 国漫质感，黄昏侧逆光，朱红与灰青对比，边缘留高光。
[Shot 1] 全景，<Subject 1> 停在 <Subject 2> 前，指尖离门环半寸；镜头固定。
[Shot 2] At 00:04.000，切中景，<Subject 1> 抬眼，说：<d>[Chinese] 父亲，三日盘缠。</d>

overall_soundscape:
黄昏风声穿过甬道，远处更鼓一响，衣料摩擦声。

non_diegetic_music:
N/A
```
```

**六段分别写什么**（顺序不可改，段名恒为英文小写 + 冒号）：

| 段 | 内容 | 常见错法 |
|---|---|---|
| `subject_definitions` | 每张图是谁、每个人/景/道具来自哪张图 | 只写「角色参考图见 <Picture 1>」—— 没有 Subject，模型不知道谁是谁 |
| `summary` | `[reference generation]` + 一段话讲目标与参考关系 | 写成剧情简介，或引入没定义过的标签 |
| `retention_analysis` | 每个标签一行 + 标记词 | 标记词自造（如 `mostly_kept`）；漏掉某个 Subject |
| `detailed_description` | 先立画风，再按 `[Shot n]` / `At MM:SS.mmm` 写动作、运镜、台词 | 写成「画面：… 运镜：…」的字段表；没有分镜切点 |
| `overall_soundscape` | 环境音、物理动作音、非语言人声 | 把台词抄进来（台词只属于 `detailed_description`） |
| `non_diegetic_music` | 只有观众听得见的配乐 | 留空（没有就写 `N/A`） |

**硬性要求**：

- 「A段」「B段」这两个标签必须**逐字**出现（引擎按它们切分；写成「分镜提示词」「视频提示词」
  或只给一个围栏，都会导致这一镜被判为「缺提示词」而丢弃）。
- 每段提示词用三反引号围栏包住，**必须闭合**（输出被截断时最后一镜会缺 B 段，那就少写一镜，
  不要留半截）。
- `<Picture n>` 的编号必须与「参考图」行的顺序**逐位对应**（1 = 分镜图，2 = 第一个参考图），
  且不超过参考图张数 + 1。
- 每个 `<Subject n>` 的定义里都要写清它来自哪张图（`是 <Picture k> 中的…`），
  `retention_analysis` 里也要有它的一行。
- 说话人写成 `<Subject n>（S1）`，编号按**发声顺序**；同一人跨镜复用同一个 `(Sx)`。
- 不许出现：`{{Mixed n}}`、`<Video n>`、`上传顺序：` 行、「禁止：…」段。
  负向词在 cfg=1 的采样下不起作用 —— 想排除什么就正面写
  （「不要跳轴」→「机位始终在轴线同一侧」）。
- B段里出现的每一句台词都必须带 `<d>[Chinese] …</d>`。转换器会把裸引号中文自动包上
  并在报告里记一条缺口 —— 但那是兜底，不是许可：兜底改的是写法，改不了已经烧进旧成片的字幕。
