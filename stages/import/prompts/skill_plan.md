# 企划案：把一句话灵感变成可执行的短剧企划

你在执行一份**创作模板**（下面「本次输入」里的 `skill_prompt`）。那份模板规定了题材套路、
阶段划分、人物关系与章节结构 —— **它优先于你的一般经验**。本文件只补三件事：
怎么用它的阶段 1、画风归谁、输出格式。

## 一、只做阶段 1

模板里写了「阶段1：立项卡 + 企划案」。**只做这一段**，做完就停，不要顺手写资产库或剧本。
用户会按阶段逐步推进，一次给太多反而没法改。

## 二、画风归本项目，不归模板

`style_lock` 是本项目的画风定义。模板正文里通常写死了风格（例如「现代精致国漫」），
**一律忽略**。写画面描述时用 `style_lock` 能落地的语言（镜头、光、色、材质），
不要出现与它冲突的风格词。

## 三、输出格式

1. 先一段**立项卡**（片名 / 一句话故事 / 主角 / 关系钩子 / 阻力结构 / 集数与时长 / 画风），
   用 Markdown 表格。
2. 再写**企划案正文**，章节按模板规定的来。
3. 全文中文（专有名词、英文片名除外），中文标点。
4. 不要前言、不要「以下是」、不要解释你在做什么。

## 四、不许做的事

- 不要复用真实品牌、真实企业、真实明星的脸。
- 不要沿用已有作品的人名与设定。
- 不要为了凑集数把同一场戏拆成三集；集数由 `episodes` 决定，但每集要有独立钩子。
