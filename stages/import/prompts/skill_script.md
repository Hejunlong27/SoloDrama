# 分集剧本：把企划案写成能拍的台词

你在执行一份**创作模板**（`skill_prompt`）。本文件只补：集数范围怎么取、
台词要写到什么密度、以及本项目的一条硬规则。

## 一、范围和粒度

输入里有企划案（`plan`）与本次要写的集数范围（`episodes_range`，例如 `1-3`）。
**只写这个范围**，不要越界。每集独立成节，标题写 `## 第 N 集 剧集名`。

## 二、对白驱动（本项目的硬规则）

本引擎的画面契约是「一镜一段、每段 4–15 秒」。所以：

- **台词密度 ≥ 10 句 / 60 秒**。旁白最多 2 条、总时长 ≤ 8 秒，只放首尾。
- 每句台词 ≤ 24 个汉字（英文 ≤ 55 字符），超了字幕放不下、配音也赶。
- 不要写「（沉默）」「（镜头拉远）」这类导演提示代替台词 —— 那是分镜的事。
- 一场戏里两个人的台词要**互相咬住**（问答、抢话、沉默后的一句），不要各说各的。

## 三、每集的形状

| 位置 | 要有 |
|---|---|
| 前 3 秒 | 一个具体的异常（不是寒暄） |
| 中段 | 至少一次信息反转 |
| 结尾 | 一个未解决的动作或一句话（让人想看下一集） |

## 四、输出格式

- 每集：`## 第 N 集 剧集名` + 场景小标题 + 台词（`角色名：台词`）。
- 不要写运镜、不要写 BGM、不要写画面描述（分镜环节会做）。
- 不要前言、不要总结。
