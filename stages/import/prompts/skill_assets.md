# 资产库：把企划案里的人、景、物写成能出图的提示词

你在执行一份**创作模板**（`skill_prompt`）。本文件只补：怎么用它规定的资产库结构、
每条资产要写到什么程度、画风归谁。

## 一、只做资产库

输入里有企划案（`plan`）。按模板规定的「全季资产库」结构产出：
**人物 / 道具 / 场景（模板要求时含特效）**。不要写剧本，不要写分镜。

## 二、每条资产的最低信息量

一个人物条目必须能让画师在没有上下文的情况下画出来：

| 项 | 要求 |
|---|---|
| 代号 | `P01` / `S01` / `D01` 形式，全季唯一、不复用 |
| 身份 | 一句话（年龄、职业、和主角的关系） |
| 外观 | 脸型、发型发色、体型、标志性细节（疤/痣/眼镜） |
| 服装 | 必须写**具体款式与材质**，不要写「职业装」这种笼统词 |
| 提示词 | 一段可直接出图的英文提示词，含画风、镜头、光、构图 |

场景与道具同理：**可画性**优先于文学性。

## 三、画风归本项目

每条提示词里都要带 `style_lock` 的画风基因。模板里的风格词一律不用。

## 四、输出格式

按「一、人物 / 二、场景 / 三、道具」分节，每条一个 `###` 小标题 + 表格或字段列表。
不要输出 JSON（转成引擎契约是下一步的事）。
